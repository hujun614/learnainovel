# 比较能抓住读者的情节类型（讨论稿）

> 只谈类型、组合和开篇优先级，不锁主角，不写分章细纲。  
> 因素定义以 `01-战斗因素种类.md` 为准。

---

## 〇、抓人，靠的是“预期被当场打破”

第一本开篇先教礼、再让暗探临门，气氛有，追读欲不足。经典修仙读者要的更简单：

> **立刻知道谁该赢、谁在找死、当场有没有牌把结果打歪；打歪之后必须惹出更大的麻烦。**

“该赢”来自位阶和门派阶梯（大宗门弟子、小宗门、散修、家族）。  
“打歪”来自功法例外、术法相克或用途、外物、禁术、场况。  
“更大的麻烦”来自条件暴露、禁术反噬、宝物换手、更高阶梯的人被惊动。

因此，能抓住人的情节，几乎都是同一句的变体：**按常理他该死 / 该输 / 该被看不起，这一场没有；但下一场会更危险。**

设定再清楚，若开篇只展示“慢功法更扎实”“黄玄地天很完整”，仍然抓不住人。功法快慢、必要条件、战阵，都要变成**有时限的冲突**，而不是世界观说明书。

## 一、先选会重复、不容易腻的几类戏

下面按“读者已经想看、而我们的因素也养得活”来排，不是按主题深刻。一类戏若全书只用一次，不值得为它加设定；若能从开篇用到中后期只换规模，才值得当主引擎。

### 1. 按门派阶梯看不起人，再当场打脸

读者默认：大宗门 > 小宗门 > 散修，家族略低。只要有人按这张表口出狂言，读者就等着看打脸。

打脸能成立，必须让例外可见、可解释：不是突然境界跳了，而是——功法品阶高于这个身份该有的、术法相克、外物补了一记、对方战阵没合拢。打完若只是“原来你很强”，戏到此结束；打完若变成“小宗门不该有这种功法，大宗门外门要来问”，戏才开始。

适合开篇到全书。越用越要提高代价：第一次打的是同门纨绔，后来打的是真能杀人的人。

### 2. 追杀、截杀、灭口

生死当场成立，不需要先介绍道统。位阶差一眼能看懂：筑基来杀练气，该跑。

抓人的点不在赢，在**不该活却活了**：场况（夜路、山门将破、比武场规矩被撕）、一张保命外物、一次禁术。活下来必须少一样东西（护身符、禁术次数、暴露来路），并被更高阶梯继续追。

第一本缺的就是这种“活过第一夜”的钩子。开篇优先用这类，身世用追的过程再漏，不要先讲完再遇险。

### 3. 夺宝、夺残篇、抢必要条件

外物补术法，功法条件苛刻——两件事都让“同一件东西不能两人各拿一份”。拍卖、秘境、灵脉、某时某地才能练的功法，都是同一类戏：

- 看见东西值多少（地阶法宝、天阶残篇、十年一遇的条件）；
- 看见谁也在抢（小宗门、散修、大宗门外门）；
- 抢到不是高潮，是通缉令。

天阶完整功法本卷不宜当奖励。**天阶残篇、地阶完整、玄阶精品**就够写争夺。条件越苛刻的功法越该把“条件”写成地点和时间，而不是写成身世彩蛋。

### 4. 三种打法轮换：清场、斩将、战阵

若每场都是两人对波，读者会腻。术法用途已经给了三种完全不同的场面，应有意轮换：

| 场面 | 爽点 | 怕什么 |
|---|---|---|
| 群攻清场 | 一人压一群，身份阶梯被当场掀开 | 碰上单攻斩将或真正的战阵 |
| 单攻斩将 | 仇人、天才、名额，一对一打死 | 被拖进人堆或战阵 |
| 战阵围杀 | 门派不像乌合之众；围杀散修老怪、压小宗门高手 | 阵眼被破、关键人被斩 |

大宗门的威胁，中段应至少有一次用**战阵**写出来，而不是只靠一个境界更高的天才单挑。小宗门、家族若要活，也必须让读者看见他们会不会阵、敢不敢阵。

### 5. 相克：会打，而不是只会升级

同境或低半境，靠术法相克赢。这是少数能让读者觉得主角“脑子在打仗”的桥段，也最适合大比和复仇。

相克要事先让读者看见两边的路数，不能赢的那一刻才宣布“克你”。组数要少，全书记住两三组就够。赢了若对方下一次换术法或换外物补相克，就有续集，而不是永远克死同一个人。

### 6. 禁术翻盘，立刻付钱

禁术短时抬位阶，是越级最干净的理由，也是章末钩子最干净的来源：这一章活了，下一章吐血、寿元、功法走火、或被识破“你用的是哪门禁术”。

全书禁术不能场场开。开篇可以用一次保命，让读者记住这张牌有多贵；中段再用，必须比开篇更贵或更暴露。否则位阶墙塌掉，门派阶梯也假了。

### 7. 快功法压人，慢功法后劲——只能当中段主菜，不能当开篇唯一主菜

这是很稳的成长对照：对手三个月一个小境，主角被笑；同境对决时扎实的那一方才被看见。它满足“逆袭”，但节奏慢。

用法：开篇用追杀、打脸、夺宝把人留住；把“练得慢”写成已经被看不起的现状，而不是写成需要读三章才能理解的理念。中段用一两场同境硬仗兑现“扎实”，让快功法真正赢过很多场，再在关键场输掉——快的不是骗子，慢的也不是天生正义。

### 8. 攀爬可见阶梯：散修 / 家族 → 小宗门 → 大宗门压力

读者喜欢地图变大、对手换档。本书可见阶梯到大宗门为止，正好三步，不必请隐世大宗上场。

每上一步，功法、术法、外物的品阶应肉眼可见地提高，战阵开始出现，忌惮从“师兄”变成“真能灭门的人”。家族平均略低，天然能写：送天才进宗门、灵脉被要、族内有人想投大宗门。这比“天下共主”更适合起步卷。

## 二、开篇优先，中段反复，后置慎用

### 开篇三章里就该出现的（选二到三样叠在一场里）

- 追杀或灭口级的生死；
- 按散修 / 小宗门 / 家族被看不起；
- 一件会惹祸的东西（残篇、法宝、功法条件暴露）；
- 一张有代价的保命牌（禁术或一次性外物）。

开篇可以没有大比、没有完整秘境、没有慢功法兑现。开篇必须有**活下来 + 惹祸**。

### 中段最耐写、可换皮重复的

- 门派大比（同境，术法 + 有限外物，规矩限制禁术）；
- 秘境（场况限境，内里夺宝、抢条件、遇战阵）；
- 相克与反相克；
- 快慢功法对照兑现；
- 大宗门以战阵或外门精英下场。

### 后置或少用，以免开篇又上课

- 隐世大宗、天阶之上、化神、上界来人；
- 制度正义、道统辩论；
- 只展示功法哲学、不附带时限冲突的日常修炼；
- 每场越级、每场打脸、每场禁术。

上界遗物若开篇就给完整的，后面没有地方涨。开篇最多给残、给祸、给一个条件，不给答案。

## 三、几种开篇组合（不锁人物，只看抓力）

下面不是大纲，是用已定因素叠出来的“第一场戏可能长什么样”。任选一种作主钩，其余可在后文当支线。

### 组合 A：家族灵脉被要，战阵已合，禁术保命

小宗门或大宗门外门来收家族灵脉，家族平均更弱，战阵一合就该灭。主角不当场打赢整支战阵（那会把位阶墙拆掉），只靠禁术或相克撕开一个口子活出去，并带走或暴露一件不该有的功法/残篇。

**当场可读**：门派阶梯、战阵、禁术代价。  
**下一章**：谁认出禁术来路，谁来灭口。  
**风险**：若写成一人屠门，后续大宗门就没有威慑。

### 组合 B：拍卖或截货，外物补术法，身份误判

散修或小宗门弟子拿着一件补术法的外物进场，被按身份报价、按身份侮辱。货一易手就有人在路上截杀。主角可以输给位阶、赢在相克或外物，但货会引来比他高一档的人。

**当场可读**：外物值多少、谁该不敢抢、谁抢了。  
**下一章**：买主、截路人、门派收赃各来一拨。  
**风险**：写成鉴定讲座，会回到第一本的慢开篇。货的利害必须用抢和杀来写，不能用介绍来写。

### 组合 C：小宗门内的名额和羞辱，比武中途生变

大比本身不够开篇，因为缺生死。要抓人，必须在比武规矩还在时就有人准备灭口，或名额背后是功法条件、残篇、送去大宗门当质子。打脸只是第一下，出了比武场才是追杀。

**当场可读**：同境术法、规矩捆手、规矩被撕。  
**下一章**：门派不敢公保，主角被推出去。  
**风险**：若前三章都在食堂和师兄对话里铺垫大比，追读会掉回第一本。羞辱必须很快变成刀。

三种里，**A 的生死最快，B 的“东西”最亮，C 的门派日常最好写但开篇最容易慢**。按“先抓住人”的目标，A 或 B 更适合当第一场；C 更适合卷一中段。也可以 A 开篇、C 作门派篇、B 作外出篇。

## 四、人物还没定，但情节已经反过来要求人物

不锁姓名和身世，只锁“要让上述戏成立，主角身上最好有的缺口”。缺口可以以后改，但现在就要避免写成全能开局。

| 若想让这类戏成立 | 主角开局最好缺什么 / 多什么 |
|---|---|
| 按阶梯打脸 | 公开身份偏低（散修、小宗门、旁支家族），暗的那一层不能开篇就亮完 |
| 追杀保命 | 有一张贵的牌，但用了就疼；不要开局就有隐世后台下场 |
| 功法条件 | 条件未满或残篇缺页，逼他出门，而不是已经练成 |
| 快慢对照 | 若走慢功法，必须在开篇就被快的人压着；若走快功法，必须有虚的隐患 |
| 术法错位 | 功法与术法品阶不要一样齐，才有“厚但不善打 / 薄但招狠” |
| 战阵 | 开篇不要已经会开大宗门级战阵；可以会破一阵眼，或只会挨 |

反派和对手也不必先定脸，先定功能：至少一个靠快功法压人的同辈；至少一个会战阵的门派力量；至少一个抢同一条件或同一残篇的人。功能可以落在同一人身上，但三类压力都要有，否则中段只剩升级。

## 五、拟采纳（供拍板）

1. 抓人公式：按常理该死 / 该输 / 该被看不起 → 这一场没有 → 立刻惹出更高阶梯的麻烦。
2. 全书主戏：门派阶梯打脸、追杀、夺宝/抢条件、清场·斩将·战阵轮换、有限相克、禁术付钱、快慢功法中段兑现、向大宗门攀爬。
3. 开篇不要以大比、秘境说明书、慢功法理念为主菜；要生死或夺宝，叠一张会惹祸的牌。
4. 开篇组合优先考虑 A（家族/小门被战阵压、禁术保命）或 B（外物易手、路上截杀）；C 放门派篇。
5. 隐世大宗、天阶之上、上界来人，继续后置。
6. 人物未定，但开局公开身份宜低、牌宜贵、功法不宜一次练成。

若这六条也成立，下一轮可以在不锁姓名的前提下，把开篇组合收成一条，并补尚未定的细档（同境深浅、法宝是否跟黄玄地天走、禁术代价）。
