# 比较能抓住读者的情节类型（讨论稿）

> 只谈类型、组合和开篇优先级，不锁主角，不写分章细纲。  
> 因素定义以 `01-战斗因素种类.md` 为准。

---

## 〇、抓人，靠的是“预期被当场打破”

第一本开篇先教礼、再让暗探临门，气氛有，追读欲不足。经典修仙读者要的更简单：

> **立刻知道谁该赢、谁在找死、当场有没有牌把结果打歪；打歪之后必须惹出更大的麻烦。**

“该赢”来自位阶和门派阶梯（大宗门、皇朝官差、小宗门、家族驻地、劫修）。  
“打歪”来自功法例外、术法相克或用途、外物、禁术、场况，以及家族外派不是一个人在打仗。  
“更大的麻烦”来自劫修没死绝、驻地丢了不该丢的东西、或更高阶梯被惊动。

因此，能抓住人的情节，几乎都是同一句的变体：**按常理他该死 / 该输 / 该被看不起，这一场没有；但下一场会更危险。**

设定再清楚，若开篇只展示“慢功法更扎实”“黄玄地天很完整”，仍然抓不住人。功法快慢、必要条件、战阵，都要变成**有时限的冲突**，而不是世界观说明书。

## 一、先选会重复、不容易腻的几类戏

下面按“读者已经想看、而我们的因素也养得活”来排，不是按主题深刻。一类戏若全书只用一次，不值得为它加设定；若能从开篇用到中后期只换规模，才值得当主引擎。

### 1. 按门派阶梯看不起人，再当场打脸

读者默认：大宗门 > 皇朝/中型宗门 > 小宗门，家族略低。打脸放在**门外**：外派路上、驻地迎官、与大宗门弟子同行清剿。家里不是羞辱场——关起门来可以吵，不写成族内反复踩男主。

打脸能成立，必须让例外可见：功法品阶、术法相克、外物、或族人及时赶到（团结的可见牙齿）。打完若只是“原来你很强”，戏到此结束；打完若变成劫修要报仇、或官差开始打量这户人家，戏才开始。

### 2. 追杀、截杀：开篇用流窜劫修

生死当场成立。前期世界还稳，正规门派不随便灭人的家，死人先出在路上——**流窜劫修**就是专门写给开篇的刀。

抓人的点不在赢，在**驻地不该破却破了一角、人不该死却差点死**：夜路、矿驿、护商、边仓。保命靠禁术、外物、或同门族人。活下来必须少一样东西，并且劫修不是打手就散的杂鱼：他们会缠、会再来、手里可能有不该有的器物。

第一本缺的就是这种“活过第一夜”的钩子。开篇用外派遇险，家底在追的过程里漏，不要先在家庙讲完再出门。

### 3. 夺宝、夺残篇、抢必要条件

外物补术法，功法条件苛刻——两件事都让“同一件东西不能两人各拿一份”。拍卖、秘境、灵脉、某时某地才能练的功法，都是同一类戏：

- 看见东西值多少（地阶法宝、天阶残篇、十年一遇的条件）；
- 看见谁也在抢（小宗门、散修、大宗门外门）；
- 抢到不是高潮，是通缉令。

天阶完整功法本卷不宜当奖励。**天阶残篇、地阶完整、玄阶精品**就够写争夺。条件越苛刻的功法越该把“条件”写成地点和时间，而不是写成身世彩蛋。

### 4. 三种打法轮换：清场、斩将、战阵

若每场都是两人对波，读者会腻。术法用途已经给了三种完全不同的场面，应有意轮换：

| 场面 | 爽点 | 怕什么 |
|---|---|---|
| 群攻清场 | 一人压一群，身份阶梯被当场掀开 | 碰上单攻斩将或真正的战阵 |
| 单攻斩将 | 仇人、天才、名额，一对一打死 | 被拖进人堆或战阵 |
| 战阵围杀 | 门派不像乌合之众；围杀散修老怪、压小宗门高手 | 阵眼被破、关键人被斩 |

大宗门的威胁，中段应至少有一次用**战阵**写出来，而不是只靠一个境界更高的天才单挑。小宗门、家族若要活，也必须让读者看见他们会不会阵、敢不敢阵。

### 5. 相克：会打，而不是只会升级

同境或低半境，靠术法相克赢。这是少数能让读者觉得主角“脑子在打仗”的桥段，也最适合大比和复仇。

相克要事先让读者看见两边的路数，不能赢的那一刻才宣布“克你”。组数要少，全书记住两三组就够。赢了若对方下一次换术法或换外物补相克，就有续集，而不是永远克死同一个人。

### 6. 禁术翻盘，立刻付钱

禁术短时抬位阶，是越级最干净的理由，也是章末钩子最干净的来源：这一章活了，下一章吐血、寿元、功法走火、或被识破“你用的是哪门禁术”。

全书禁术不能场场开。开篇可以用一次保命，让读者记住这张牌有多贵；中段再用，必须比开篇更贵或更暴露。否则位阶墙塌掉，门派阶梯也假了。

### 7. 快功法压人，慢功法后劲——只能当中段主菜，不能当开篇唯一主菜

这是很稳的成长对照：对手三个月一个小境，主角被笑；同境对决时扎实的那一方才被看见。它满足“逆袭”，但节奏慢。

用法：开篇用追杀、打脸、夺宝把人留住；把“练得慢”写成已经被看不起的现状，而不是写成需要读三章才能理解的理念。中段用一两场同境硬仗兑现“扎实”，让快功法真正赢过很多场，再在关键场输掉——快的不是骗子，慢的也不是天生正义。

### 8. 地图变大：稳世驻地 → 国别对抗 → 中小洗牌

本书主结构不是“散修一路加入更大的门”，而是**同一户人家，世界从稳到不稳**。前期在外派半径里打劫修、见官差、见友族；中后期国别对抗一起，驻地突然变成前线，友族可能变敌，劫修可能变成某国的脏刀。

对手换档靠格局变，不靠男主改户口。大宗门和皇朝前期是稳定的天，后期才变成必须站队的火。家族灵脉被要、小门被吞，放到破局之后，不放到开篇。

## 二、开篇优先，中段反复，后置慎用

### 开篇三章里就该出现的（选二到三样叠在一场里）

- 外派任务或驻地上的生死（流窜劫修）；
- 家族不是一个人在打：同门、传讯、事后关门会议；
- 一件会惹祸的东西（劫修抢走或留下的器物、残篇、名单）；
- 一张有代价的保命牌（禁术或一次性外物）。

开篇可以没有大比、没有灭门、没有国战。开篇必须有**活下来 + 劫修没完**。家里的和睦用外派前后的书信、支援、责骂来写，不要用三章家宴代替第一场刀。

### 中段最耐写、可换皮重复的

- 门派大比（同境，术法 + 有限外物，规矩限制禁术）；
- 秘境（场况限境，内里夺宝、抢条件、遇战阵）；
- 相克与反相克；
- 快慢功法对照兑现；
- 大宗门 / 皇朝以战阵或官差下场（破局之后，不在开篇）；
- 家族关门吵架、对外仍是一块。

### 后置或少用，以免开篇又上课

- 隐世大宗、天阶之上、化神、上界来人；
- 制度正义、道统辩论；
- 只展示功法哲学、不附带时限冲突的日常修炼；
- 每场越级、每场打脸、每场禁术。

上界遗物若开篇就给完整的，后面没有地方涨。开篇最多给残、给祸、给一个条件，不给答案。

## 三、开篇组合（已收束到外派）

家门稳、灭门戏后置。第一场刀放在门外。细目和感情线见 `03`。

### 组合 A（优先）：驻地或护卫任务遭遇流窜劫修

男主带族人、或与友族/驻军同行，在矿驿、商路、边仓遇上劫修。当场可以死士卒、丢货、破一角墙，但不能把老家写没。男主不当场剿灭整股劫修，只活下来、留下纠葛：头目没抢到要的、或抢走了不该亮的东西。

**当场可读**：劫修狠、驻地能打但不能当家、族人不是路人。  
**下一章**：劫修再来，或发现他们手里有皇朝/大宗门的物件。  
**风险**：写成一次性山贼，后面没有缠；或写成男主一人屠尽，家族团结没牙齿。

### 组合 B：外派途中截货，劫修与“看不起家族的同行”叠在一起

护送或押运时，既有劫修截路，也有同行的大宗门弟子/官差按身份口气。货的利害用抢和杀来写。打脸可以有，但第一仇人仍是劫修，避免开篇就和大宗门开战（与前期稳定冲突）。

**风险**：官差戏抢过劫修戏，会把稳世设定写穿。

### 组合 C：后置——家门被要、战阵压境

原“灵脉被要、战阵已合”放到**国别对抗、平衡打破之后**，那时才合理。开篇用会直接否定“前期较稳定”。

大比、门派名额同样后置，可作卷一中段日常，不能代替第一场刀。

## 四、人物还没定，但情节已经反过来要求人物

不锁姓名和身世，只锁“要让上述戏成立，主角身上最好有的缺口”。缺口可以以后改，但现在就要避免写成全能开局。

| 若想让这类戏成立 | 主角开局最好缺什么 / 多什么 |
|---|---|
| 按阶梯打脸 | 公开是某户外派子弟，不是隐世嫡子；打脸发生在驻地和路上 |
| 追杀保命 | 有一张贵的牌，但用了就疼；不要开局就有隐世后台下场 |
| 家族团结 | 身边至少有一个能吵能帮的族人；支援可以迟到，不能从不相干 |
| 功法条件 | 条件未满或残篇缺页，外派本身可以是为了凑条件 |
| 快慢对照 | 若走慢功法，开篇就被劫修或同行的快功法压着 |
| 术法错位 | 功法与术法品阶不要一样齐 |
| 战阵 | 开篇家族只会小范围护卫阵，不会开大宗门级围杀 |

对手先定功能：开篇至少一股会缠的劫修；中段至少一个快功法同辈或傲的官差；破局后至少一股会战阵的国/门力量。劫修后期可以改身份（被收编、本是弃子），但开篇不要揭完。

## 五、拟采纳（供拍板）

1. 抓人公式不变：按常理该死 / 该输 / 该被看不起 → 这一场没有 → 立刻惹出更大麻烦。
2. 开篇收束为外派/驻地 vs 流窜劫修（组合 A 优先，B 可叠官差口气，家门被压后置）。
3. 全书主结构改为稳世 → 国别破局 → 中小洗牌，不是散修攀门。
4. 打脸、大比放门外或中段；家里以团结为底，矛盾关起门来写。
5. 隐世大宗、天阶之上、上界来人，继续后置。
6. 人物缺口、感情线的取舍见 `03`。
