# 人物升格与家族事业线

> 正典。开篇身份、境界、关系仍以 `05` 为准。本文管的是这些人**往后长成什么**，以及沈家这门事业怎么从守矿变成在天澜城发籍。  
> 未写死的结局可在各卷细纲里改；不能改开篇身份，不能改「关起门来是一家」，不能改男主不弃族。

---

## 一、家族事业：沈家到底靠什么往中心走

不是出了一个天才所以搬家。沈家的产品是**脉**。

| 层 | 是什么 | 谁主事 |
|---|---|---|
| 手艺 | 识石、识砂、开封口、把死脉打通 | 望川（术）、江蘅（识）、族里老人（经验） |
| 护卫 | 把脉守住，把来抢的人挡在门外 | 望恒（阵与战）、衡海过渡 |
| 籍与账 | 矿照、名籍、联姻、府邸、税 | 望乔（政）、衡山压舱 |

《沉石诀》把人养成能扛的石；《穿石锥》把石里的路凿开。打仗是护手艺，不是手艺本身。中域肯让沈家进天澜城，是因为中域废脉打不开，南域这户土户能打开——不是因为望川能单挑三宗。

**事业线的可见产物**（每阶段至少一件，读者能指出来）：

1. 黑水矿照（租的）
2. 墨晶脉的解释权（自己的）
3. 苍州城别院
4. 南域矿盟一席 / 南溟城沈府
5. 中域一口废脉的开凿权
6. 天澜名籍 + 天澜城沈府

## 二、沈望川 · 事业线（人）

开篇卡见 `05`。下面只写他怎么从三郎长成小界顶级，以及硬伤怎么变形——硬伤不删，删了人就漂。

### 1. 欲的升级（每一档都要让读者说得出口）

| 阶段 | 他自己要什么 | 不能写成 |
|---|---|---|
| 卷一 | 那份筑基资粮；守满这一届 | 只有责任 |
| 卷二三 | 残篇后半；把沈家从「租矿的」变成「能解释深脉的」 | 突然要当苍州城主 |
| 卷四五 | 南域承认；金丹；让青石坞的人能在南溟城抬得起头 | 弃族求南溟宗内门 |
| 卷六七 | 中域一席灵脉；元婴；给沈家一张中域名籍 | 闭关成仙、家人在南域等他 |
| 卷八 | 化神；天澜城的本宅；成为能给人籍的人 | 一人灭界、清空棋盘 |

「能给人籍」不是当皇帝。是：有人像厉铮那样求一个地址时，沈家接得住、也拒绝得起。终局的对照必须写出来。

### 2. 硬伤变形（每卷仍须兑现，由具体的人当面戳破）

| 硬伤 | 边地形态（卷一） | 南域形态 | 中域形态 | 化神前必须完成的变 |
|---|---|---|---|---|
| **A 先扛后说** | 伤、匣、根基自己担 | 把南域的局一个人扛，家主位置空着 | 对三宗不说沈家底牌，连望乔也被瞒 | 先说再扛。不说的只剩必须瞒的天机，不是面子 |
| **B 先救眼前人** | 丢库、丢图、迟援 | 为救青桐/族人放弃南溟一次名额 | 为救一个人得罪一口废脉的买方 | 能把眼前人和大账放在同一张桌上选，选完认 |
| **C 不认自己在争** | 说「我只是尽责」 | 说「我为了家」，其实也想要南溟那席 | 说「沈家需要」，其实也想要化神 | 当众承认：我要那座城，我要那口脉，我要那张籍 |

卷一仍按 `09` 兑现。卷四起每卷至少各兑现一次变形后的硬伤，不能只在旁白里宣布他改了。

### 3. 境界与公开身份

公开身份始终是**沈家的人**。可以是主事子弟、家主、沈府家主，不可以是「某宗真传跑路回来的」。打脸永远发生在门外：驻地、城门、大比、拍卖、名籍衙门。

境界节奏见 `14`。原则：

- 破境必须与守住的人、打开的脉、家里认下的账绑在一起；
- 终局化神，仍打赢局，不靠临时再拔一个大境；
- 同辈对照一直在：边地是望恒的疾路，南域是南溟天才，中域是三宗真传。快功法要真的赢过很多场。

### 4. 他与「籍」的私情

他幼时未必懂籍。卷一听厉铮把「籍」说出口，才第一次把这个字和沈石的死、和自己的矿照放在一起。此后他要的每一样东西，底层都是地址：资粮是族里的地址，矿照是州里的地址，南溟府是域里的地址，天澜府是小界中心的地址。

写他时不要反复喊这个字。让他在每一次搬家的夜里，清点活人，再看一眼新府的门——和卷一清点矿营是同一套动作。

## 三、家族三根梁

### 沈望乔 · 账与政（准家主 → 真家主）

开篇：练气圆满三年破不了筑基，留坞协理。资粮给他未必成。

**他的事业线比望川更像「家」本身。**

| 阶段 | 他做什么 | 要避免 |
|---|---|---|
| 卷一 | 护弟、提让、卷末把资粮投给望恒 | 写成只会让的圣人 |
| 卷二三 | 承认自己可能破不了；转向算账、矿照、联姻 | 突然顿悟破境抢回主角光 |
| 卷四五 | 在南溟城把沈府立起来的人是他，不是望川 | 变成秘书 |
| 卷六八 | 家主。名籍、联姻、对天澜朝的文书，他拍板 | 望川在外当家主、他在家养老 |

境界可以停在筑基或金丹初期——**故意停**。家主之才不在破境。读者要在南溟城的一次谈判里看见：没有望乔，望川打下来的东西会从文书上滑走。

惧：耗到最后，家搬进了中心，里面却没有他的位置。欲：让沈家在下一档地理里仍是一家，而不是望川的随员。

### 沈望恒 · 阵与战

开篇：练气中期，疾路，抢功，也想要那份资粮。

| 阶段 | 他做什么 |
|---|---|
| 卷一 | 拿到资粮；第一次把话说开 |
| 卷二 | 资粮在手却卡住，尝到望川卡过的滋味；和解 |
| 卷三 | 可调开关：担罪或死（`10` 的 M2）。**若他活着**，则成为沈家战阵的芯 |
| 卷四以后（若活） | 从三才阵长成能守府、守脉、守城的阵眼。中域看不起的「土阵」，要在一场围杀里打出牙齿 |

若卷三他死：战阵这根梁必须有人接（衡海残、族中下一辈、或青桐入沈家后的卫家阵法混编）。死得起，接得上也要写。默认建议：**卷三重伤或担罪，不死**，让这根梁长到中域——家族崛起文少一根梁会空。

欲：被正眼看一次。惧：一辈子是「冲得快但不稳的那个」。中域阶段，让他的疾路真正赢过一场元婴都在看的阵战，再在关键场把稳交给望川。快的不是骗子。

### 沈衡山 · 压舱石

开篇：家主，筑基中期，坐镇本家，按住想喊的人。

他的弧：按住 → 布置 → 把家主交给望乔 → 守祖宅。

卷五南溟立府时，他可以不去，留在青石坞。**本宅迁走、家主留下守根**，比全族搬空更像这家。卷六以后他可以老、可以境不再涨，但青石坞那口小灵脉因为他还在而仍是沈家的。

惧：这一代分不匀，家从里面裂。欲：沈家在下一档仍有一张椅子——后来发现椅子可以有两张：祖宅一张，中心一张。

### 沈衡海 · 外事的过渡

开篇：筑基初期，支援迟到，骂人、补防、对矿监扛事。硬伤 A 的家族镜像。

弧：外事扛着 → 受伤退二线 → 把外事交出去。交的过程要疼。卷四他可以仍是南域的脸，中域不必他去。他是望川在自己身上看见的那条路：先扛后说的人，最后要把说的机会留给后辈。

## 四、感情线（三条认真，随地理换齿）

避开开篇定情冷冻，也避开后宫收集。三条都认真过，不必三条都跟到天澜城。

### 1. 卫青桐 · 战友线（南域的人）

开篇见 `05`。她是边地并肩的人，账从铜料车开始。

| 阶段 | 齿 |
|---|---|
| 卷一 | 并肩、算赔、迟援之怒、骂完仍回来 |
| 卷二三 | 卫家与沈家站队可能不同；高潮是立场 |
| 卷四五 | 沈家进南溟，卫家未必跟得上。她要自己拿一次主意：跟，还是把卫家留在苍州当沈家的根与眼 |
| 中域 | 默认她**可以不进天澜**。不是感情失败，是两户的地址不再同一档。若进沈家成自己人，也须带着卫家的账，不是跟班 |

她自己要什么：被当成能商量事的人。惧：两户绑在一起，赔的总是小的那户——沈家越往中心走，这条惧越真。所以这条线的终局可以是「人是你的，账是族里的，地址各写各的」。

### 2. 江蘅 · 身份会炸的线（中域的路标）

开篇：识矿、开价、不认恩。册子被划掉。

**全书功能**：她是沈家走进中域的活人接口。没有她，穿脉仍是南域手艺；有她，手艺对得上中域的册和废脉。

| 阶段 | 齿 |
|---|---|
| 卷一 | 余党 → 开价 → 半个来历 |
| 卷二三 | 来历七分；为自己做一件事，不是为交易 |
| 卷四 | 她可以走。南溟城的册开始有人来问她 |
| 卷六 | 无相楼或天澜朝的弃籍正面落地。她的账收在她自己身上 |
| 卷七八 | 去留由她。留下也不入沈家籍——她怕籍，这是她的硬伤 |

她不是货物，也不是男主的中域通行证（人可以领路，籍必须沈家自己挣）。欲：活着，并且不再被谁记在册子上。惧：再被当成一件有用的东西转手。沈家越需要她识脉，这条惧越要被当面问出来。

### 3. 石晚宁 · 家事压秤（苍州的绳子）

铁石宗旁支。开篇只闻其名。卷二出场，须有自己的主张。

她是**苍州这一档的联姻政治**，不是中域女主。卷五以前把这根绳子收完：亲事让出去、强留、或她自己把绳子剪了。中域不必跟着，除非她把自己变成沈家账房的人——那是望乔的线，不是感情线抢戏。

## 五、开篇敌与官差，怎么长进全图

### 厉铮

开篇敌。要匣，换一个籍。被灭口。

全书功能不随他的死而结束：

- 余党、被收编的脏刀、同一股戟纹，卷三再来；
- 中域有更干净的灭口手法，卷六让望川认出「当年西谷那一下」的高级版；
- 卷八，望川能给人籍的时候，必须有一场对照：一个求籍的人站在沈府门口。可以是余党的后人，可以是另一个散修。不写成励志收徒，写成他知不知道厉铮为什么死。

### 周启年

北寒矿监。烦，不是反派。矿账压着他。

卷二三：倒向一边或被处理掉（`10` 的 L4）。  
若他活着：卷五可以在南溟城再遇见——边地官差进了都城，人也小了。这是「地理即地位」落在配角身上的一刀，比他当反派更有用。

## 六、后文才需要的人（先锁功能，姓名可改）

不在开篇报幕。进入该卷前写入当卷人物卡。

| 功能 | 大约何时 | 说明 |
|---|---|---|
| **南溟宗真传**（快功法同辈） | 卷四大比 | 望恒那条对照的升级。要真的压得住望川一场 |
| **南域矿盟盟主 / 掌事** | 卷四～五 | 买方。看不起土户，又需要土户的脉 |
| **廊州过路的中域执事** | 卷五末 / 卷六初 | 第一次用中域口气把沈家叫成南边来的 |
| **天澜世家诱饵** | 卷六 | 把一口废脉「赏」给沈家，等他们开了再收 |
| **无相楼中人**（江蘅册子的活口） | 卷六 | 身份爆炸的对面，不是爱情对手 |
| **衡云山门长老** | 卷六～七 | 开篇买矿气味的老家。可恨在把南域当料场 |
| **化神坐镇之一** | 卷七～八 | 天花板。有自己的欲，不是最终关卡木桩 |
| **求籍者**（终局对照） | 卷八 | 厉铮的回声 |

郝家散掉之后，南溟城和天澜城各准备一户内斗对照，换皮不换公理。

## 七、沈家规模怎么长（可见，不写族谱）

| 阶段 | 可见规模 | 读者应感到 |
|---|---|---|
| 卷一 | 筑基两名，练气骨干三名，族兵十余 | 一户守矿的人家 |
| 卷三 | 仍是这一户，但苍州城有人知道沈家 | 边地户进了城 |
| 卷五 | 金丹至少一名（望川），南溟府里有执事、护卫、账房 | 名门，仍能在一顿饭里认出卷一那些人 |
| 卷八 | 元婴 / 化神压阵，天澜府 + 青石坞祖宅 | 世家。门外是中心，门内仍是一家 |

族兵、旁支、姻亲可以增，但**开门的那顿饭**必须还能坐下卷一的核心：衡山、衡海、望乔、望恒、望川。少了谁，要在空位上写出来。

## 八、写作边界（全书）

- 望川不改户口。加入任何宗门只可做客卿、外盟、一度借住，籍仍写沈家。
- 望乔不抢终局破境。家主戏在文书和联姻上赢。
- 青桐不写成只疗伤；江蘅不写成只带路；石晚宁不拖过卷五还只是名字。
- 新域每进一档，先有一个看不起沈家地址的人开口。
- 搬家场面必须清点活人——和卷一天亮后的清点是同一支笔。
