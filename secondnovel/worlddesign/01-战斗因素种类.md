# 战斗因素种类（讨论稿）

> 分类、定权重，并说明每种因素能写什么情节。  
> 功法、术法的大品阶（黄玄地天）已定；同境细档、法宝分档、具体功法名仍不定。

---

## 〇、先定一条胜负总原则

如果永远是境界高的人赢，战斗没有戏，全书只剩升级。  
如果什么都能破境界，境界没有威慑，升级也没有戏。

本书采用经典修仙读者已经习惯、也最利于写情节的折中：

> **位阶是基础实力的表现。功法补充并塑造这份基础。术法决定力怎么打出去，外物补充术法。大境界仍是墙；墙内靠功法、术法、外物打牌；翻墙必须出血、留把柄，或用掉一张以后没有的牌。**

| 读者立刻感到的 | 下一章自然要写的 |
|---|---|
| 大境界压人 | 逃、忍、借势、攒破境资本 |
| 同境有输赢 | 夺功法、夺术法、夺宝、相克、战阵、比试 |
| 越级赢了 | 禁术反噬、暴露功法来路、宝物没了、仇家升级追杀 |
| 越级输了 | 仇恨、耻辱、必须换打法，而不是只去闭关 |
| 按门派阶梯误判 | 打脸或反杀；随后被真正的门派盯上 |

第一本把“名正言顺才有力”做成主题技，读者要先懂制度才觉得爽。第二本换成谁都懂的：**境界是墙，功法定底子，术法加外物是拳头。**

---

## 一、为什么战斗因素要先于人物和地图

情节里反复出现的桥段，其实都是在调动某类战斗因素：

- 开篇要抓住人：当场就要让读者看出**谁该赢、为什么可能不赢**。
- 宗门大比、夺宝、追杀、秘境、复仇、按门派看不起人：每一种都依赖不同因素组合。
- 主角成长：若只有境界一条轴，中段必然注水；若因素太多且权重相近，读者记不住谁强。

所以要回答的是：

1. 有哪几**类**东西能改胜负？
2. 哪几类要写成全书主引擎（反复抢、反复丢、反复被揭）？
3. 哪几类只作调味，免得重蹈第一本“设定先于情节”的问题？

## 二、六类因素（修订）

仍保持六类，但把原来混在“手段、本钱”里的东西拆开，按**基础实力**和**打出去的方式**分开算。其他体系（暂不命名）可以对同一张表换皮。

两层读法：

```text
基础实力 ≈ 位阶 × 功法（禁术可短时抬位阶）
打出去   ≈ 术法 × 外物（实战作小修正）
这一场   ≈ 再乘场况，并受因果忌惮约束
```

资质、根基、寿元不再单列成“本钱”大类：根基主要由功法快慢决定，入口条件并进功法的必要条件，寿元将尽仍可作为个别人的隐患，不单独成体系。

### 1. 位阶：基础实力的表现

**包括**：大境界（凝气→化神）；同境深浅（未定名）；刚破境不稳或旧伤未复。

**全书要营造的势力预期**（不是第六套修炼，而是读者一看就懂的“这人背后有多厚”）：

| 可见阶梯 | 典型观感 | 本书是否入场 |
|---|---|---|
| 隐世大宗 | 高于大宗门；功法可在天阶之上 | **不入场**，只作传闻 / 天花板 |
| 大宗门 | 功法、术法、外物整体最好；同境通常压下一档 | 入场。前期与皇朝对峙、求内部稳定；中后期是国别对抗的一极 |
| 中型宗门 / 部分地域称皇朝 | 一地之主。有的地方披“国”的皮，有的披“门”的皮，实力档相近 | 入场。前期稳定；国别对抗起来后，是打破平衡的另一极 |
| 小宗门 | 有传承但不完整；同境能打，缺底牌 | 入场。前期安于一隅，后期被卷进站队 |
| 家族 | 结构类似同级宗门，**平均略低**；团结的家族靠战阵、轮换外派和“得罪一家即得罪一窝”补差距 | 入场。男主家关起门来是一家；开篇不写灭门 |
| 散修 | 功法杂、术法野、没后援；个别狠、个别菜 | 入场 |
| 流窜劫修 | 秩序外的刀，不是正规阶梯。前期被各方默契清剿；后期可被大势力收编当脏手 | **开篇纠葛对象** |

同境并不自动相等。大宗门练气中期，常常仍压得住小宗门练气后期、散修练气圆满——读者应先感到门派阶梯，再感到个人例外。例外一旦出现（散修手里有地阶功法、小宗门弟子会相克术法），就是戏，也必然引来更高阶梯的觊觎。

**前期稳定**：顶级势力要对得住，自己内部先不能乱，因此暂时不拿中小势力开刀。中小也乐得纳税、供人、守驻地。世界看起来太平，并不等于没有死人——死人先出在路上和驻地，出在劫修手里。

**后期破局**：国与国、或皇朝与大宗门撕破脸之后，清剿默契先停，劫修变刀；中小必须站队、联姻、献地或装死。不团结的家族在这一段被证明活不下去；团结的也要付个人代价，不是自动胜利。

**情节功能**：告诉读者“正常情况谁该赢”，制造压迫和升级欲望。

**写作约束**：大境界不应被嘴炮、顿悟、无铺垫的友情光环打破。同境可以翻；大境翻盘必须动用功法例外、术法相克、外物、禁术或场况，并且留下代价。

### 2. 功法：对位阶这份基础的补充

功法不直接等于“打人的招”，而是**把人修成什么样、基础有多厚、涨得有多快**。品阶已定：

> 黄阶 < 玄阶 < 地阶 < 天阶。本书可见上限为天阶。天阶之上属隐世大宗，本卷不出现完整传承。

同一品阶内部，还有三种会改情节的特性（暂不拆更细的子档）：

| 特性 | 通常观感 | 情节牙齿 |
|---|---|---|
| **练得快** | 同资源下境界涨得猛 | 对手短期压人、门派爱收、后劲可能虚 |
| **练得慢、根基更扎实** | 同境更抗打、后手更稳，别人已先一步成名 | 被嘲、被赶超，中后期同境反压；开篇不能只靠它，太慢 |
| **必要条件** | 体魄、生辰、材料、地形、血脉等；**条件越苛刻，通常越强** | 逼人冒险、赶时间、与人抢同一条件；得到后也被人按条件反推来路 |
| **禁术** | **一般可以临时提升基础实力（位阶）** | 翻盘神技；打完必须反噬、暴露或留下标记，否则墙就塌了 |

快与慢可以写在同一部功法的两条路，也可以是两部功法对照。不要做成“慢的永远更道德、快的永远是反派”；快功法可以真的强、真的赢过很多场，慢功法的好处必须在同境对决里被读者看见，不能只在旁白里宣布“根基扎实”。

黄阶功法配高位阶，仍可能被地阶功法的低一境压得很难看——这是门派阶梯能成立的原因：大宗门不是人多，是功法品阶整体更高。

**写作约束**：不要给每个大境界固定“一招成名神通”。读者跟的是**这部功法快还是慢、缺什么条件、禁术能抬多久**。完整天阶、天阶之上，本卷不当作可练成的日常奖励。

### 3. 术法：力怎么打出去

术法是原“手段”里真正的招式层。品阶同样走 **黄 < 玄 < 地 < 天**，可与功法品阶错位：地阶功法配黄阶术法，是厚但不善打；黄阶功法配地阶术法，是薄但招狠。错位本身就是人物和门派差异。

术法还有三类会改战局的特性：

| 特性 | 含义 | 情节牙齿 |
|---|---|---|
| **相克** | 有的术法克有的术法（或属性、路数） | 同境或略低境可以赢，读者觉得“会打”，不是无脑升级 |
| **群攻** | 一打多，清场强 | 一人压一群杂鱼的爽感；对上单攻斩将或战阵时可能吃亏 |
| **单攻** | 一对一、斩将 | 大比、仇敌对决；被群攻或战阵拖死时的无力 |
| **围杀 / 战阵** | 多打一，训练过的配合，效果明显好于乌合之众 | 大宗门的牙齿：围杀散修老怪、压小宗门高手；被拆阵则崩 |

群攻、单攻、战阵不是品阶，是**用途**。地阶群攻未必打得过黄阶单攻的斩将，战阵也未必围得死会破阵的单攻——这样才有战术，而不是比谁品阶字母大。

**实战能力**：有时会影响结果，但是**小修正**，不是第三套品阶。典型差在：大宗门天才没杀过人，散修老油条会阴、会逃、会判断何时禁术。适合写一两场名局（天才第一次流血，或阴招被正面对破），不要每场都靠“实战经验”翻盘，否则位阶和品阶都假了。

**写作约束**：术法按人物和传承走。相克要少、要记得住，不要做成读者必须背的元素表。战阵算术法，不算场况里的“人多”；乌合之众围不上会战阵的人。

### 4. 外物：术法的补充

**包括**：法宝 / 灵器；符箓；可带走的阵盘；灵兽、傀儡。丹药、护身符等消耗品默认也放这里。

外物补的是**术法打不出去或打不厚的那一块**：没好地阶术法，可以用法宝硬接、硬砸；术法是群攻，外物可以补一记单攻斩将。它不是第二套功法。

少数丹药或禁器可以短时补位阶，效果上接近禁术，必须同等给代价或次数，避免人人吞一粒就破境。

**情节功能**：最适合写“抢”。物件换手，势力关系就变。

**写作约束**：外物可以让低境活过不该活过的一击，但应是次数有限，或目标太大引来更强的人。法宝细档下一轮再定，可考虑与黄玄地天对齐，不必另造名称。

### 5. 场况：这一场才成立的条件

**包括**：地利、天时、灵气浓度；固定山门 / 秘境规则；当场伤势与灵力余量；临时人数（不是战阵）；情报与预谋；当场不许破的规矩（比武、圣地、同门不可开杀）。

**与战阵的区别**：场况里的人多，只是人多；战阵是练过的围杀术法。秘境“限筑基以下”是场况；进了秘境再用战阵围杀，是场况套术法。

**情节功能**：开篇、逃亡、围杀、比试最常用。读者不需要新名词，只需要看见“地方不对、规矩捆着手、人已经受了伤”。

**写作约束**：用一次就应改变下一场的条件（人受伤、阵破了、规矩被当众撕破）。

### 6. 因果与忌惮：长线钩子

**包括**：气运；仇怨；身份后台（大宗门不会轻易对小宗门痛下杀手，除非值得）；道心 / 心魔；上界影子。隐世大宗作为忌惮源可以存在于传闻里，本卷不现身。

**情节功能**：解释“为什么强者不立刻打死弱者”，以及“赢了为什么更麻烦”。按门派阶梯误判之后，真正的忌惮往往来自“这功法/术法不像小宗门该有的”。

**写作约束**：忌惮可以救人，但不能每场都靠“对方投鼠忌器”幸免。气运可以偏一点，不可写成无敌光环。

## 三、建议的权重

### 基础硬：位阶 × 功法

谁该怕谁，先看境界，再看功法品阶和快慢。门派阶梯成立，主要因为功法整体更高，不是因为姓氏发光。

### 出手硬：术法（外物为其补充）

同境怎么打、为什么要夺传承和夺宝。开篇三章里，至少要让读者看见**基础硬里的一项**和**出手硬里的一项**在打架。

### 软：场况、禁术、实战、忌惮

翻盘用。每次必须有条件或代价。禁术短时抬位阶，是最强的软牌，也是最必须付钱的牌。实战只作小修正。

### 小界专属

- 金丹已是豪强，元婴极少，化神只存在于离去、传说和残骸。
- 可见最高传承停在天阶；完整天阶应极稀，残篇就足以驱动整卷争夺。
- 偶发上界遗物属于外物 + 忌惮：能越阶，也把更大的猎人引进来。
- 隐世大宗不入场，避免本卷刚开就被更高阶梯掐死。
- 前期正规势力较稳；开篇敌用流窜劫修。家族团结补的是战阵、轮换外派和忌惮，不补到能单挑皇朝。

## 四、一场能写的战斗，用什么配方

重要战斗仍固定成可读的三层，不把六类同时堆上：

```text
基础差（位阶 × 功法，谁该赢）
+ 出手差（术法用途 / 相克 / 外物，最多再加一个场况）
+ 一张有代价的牌（禁术、一次性外物、战阵是否成形、秘密身份）
```

胜负揭晓时，必须发生下面至少一件事，否则这场打完情节不前进：

- 一张牌用掉或被夺；
- 功法条件、禁术反噬或术法来路暴露；
- 伤势留下把柄；
- 当场规矩被打破，门派关系改写。

**打完要少点东西，或多点麻烦。**

## 五、六类因素各自能养活的情节类型

细目见 `02-吸引读者的情节类型.md`。此处只核对：想写哪类戏，对应因素必须有牙齿。

| 想写的戏 | 主要靠 | 若权重反了，会变成 |
|---|---|---|
| 按门派看不起人、打脸 | 势力阶梯预期 × 功法或术法例外 | 读者也不知道这人为什么能打 |
| 快功法压人、慢功法后劲 | 功法快慢 | 只有旁白说根基扎实 |
| 为苛刻条件冒险 | 功法必要条件 | 无目的秘境观光 |
| 禁术翻盘 | 短时抬位阶 + 事后代价 | 无铺垫觉醒 |
| 相克反杀 | 术法相克 | 突然宣布克制，像作弊 |
| 一人清场 / 斩将 / 战阵围杀 | 群攻、单攻、战阵三种用途 | 所有打架都一个样 |
| 夺宝 | 外物补术法 | 逛街鉴定 |
| 天才被老油条阴、或阴招被正面对破 | 实战小修正 | 每场都靠经验翻盘 |
| 开篇追杀 | 位阶压迫 + 场况 + 一张保命牌 | 散步遇险后再插身世 |

## 六、相对第一本，明确降权的东西

| 第一本的主轴 | 第二本如何安置 |
|---|---|
| 名分 / 锡命决定力的合法性 | 最多写成场况：宗门规矩、不得擅杀、比武契约 |
| 仪轨走完才有全力 | 不作为通用施法流程 |
| 血食供养网、贡道战略 | 小界可以有灵脉、灵矿，但是资源场况 |
| 每境一个标志神通 | 取消。术法跟人物和传承走 |
| 问鼎式“质疑即削弱” | 不采用。揭穿功法来路只影响忌惮，不直接削伤害 |
| 会盟阵临时抬一大境 | 战阵是术法用途，多人配合有限、可打断；禁术才短时抬位阶 |

## 七、其他体系怎么挂在这张表上

暂不命名。约定一句：

> 凡能在小界里动手的存在，都用同一套六类结算。差别只在功法从哪来、术法长什么样、外物叫什么。

例如（仅示意）：炼体偏功法里的肉身条件；邪修偏禁术与外物；妖类偏本体既是功法也是外物。冲突时读者仍然先看位阶对位和门派阶梯，再看术法怎么打、当场有没有牌。

## 八、尚未定的等级区分（留给下一轮）

已定：功法、术法、法宝走黄玄地天；同境初/中/后/圆满；本书不见天阶之上；可见阶梯为衡云宗与北寒朝；前期稳、后期矿权破局。开篇守黑水矿。

| 因素 | 仍可后补 | 不需要的 |
|---|---|---|
| 位阶 | 破境不稳的更多写法 | 每境寿元精确年数、每境神通名 |
| 功法 | 条件是否再分“严 / 极严” | 天阶之上的正式名称；全宗门技能树 |
| 术法 | 相克只做几组 | 读者必须背的元素周期表 |
| 外物 | 消耗品是否另档 | 完整器谱 |
| 场况 | 秘境常见规则类型 | 把山门阵做成第二套修炼 |
| 因果 | 气运是否量化 | 完整天道法则书 |

## 九、本轮拟采纳的结论

1. 六类改为：**位阶、功法、术法、外物、场况、因果忌惮**。原“本钱”并入功法条件与快慢根基；原“手段”拆成功法与术法。
2. 位阶是基础实力的表现；功法补充基础（品阶、快慢、条件、禁术）；术法是打法（品阶、相克、群攻 / 单攻 / 战阵）；外物补充术法；实战只作小修正。
3. 势力预期：隐世大宗（不入场）> 大宗门 > 中型宗门/皇朝 > 小宗门 > 散修；家族平均略低于同级宗门。流窜劫修是秩序外的开篇敌，不是第五档门派。
4. 功法、术法大品阶：黄 < 玄 < 地 < 天。本书可见上限天阶。
5. 禁术：一般短时抬位阶，必须付钱。
6. 胜负总原则：大境是墙；墙内靠功法、术法、外物打牌；翻墙出血。
