# 战斗因素种类（讨论稿）

> 本轮只分类、定权重、说明每种因素能写什么情节。  
> **不在这里做品阶表、子境界名、具体功法名。**

---

## 〇、先定一条胜负总原则

如果永远是境界高的人赢，战斗没有戏，全书只剩升级。  
如果什么都能破境界，境界没有威慑，升级也没有戏。

本书采用经典修仙读者已经习惯、也最利于写情节的折中：

> **大境界是硬门槛。同境之内，其他因素决定胜负。越级可以发生，但必须付代价、留把柄、或消耗一张以后用不出的牌。**

这条原则直接服务情节，而不是服务“战斗系统完整”：

| 读者立刻感到的 | 下一章自然要写的 |
|---|---|
| 大境界压人 | 逃、忍、借势、攒破境资本 |
| 同境有输赢 | 夺宝、偷学、埋伏、比试、翻旧账 |
| 越级赢了 | 伤、暴露、欠债、宝物没了、仇家升级追杀 |
| 越级输了 | 仇恨、耻辱、必须改手段，而不是只去闭关 |

第一本把“名正言顺才有力”做成主题技，读者要先懂制度才觉得爽。第二本把这句话换成谁都懂的：**境界是墙，墙内打牌，翻墙要出血。**

---

## 一、为什么战斗因素要先于人物和地图

情节里反复出现的桥段，其实都是在调动某类战斗因素：

- 开篇要抓住人：当场就要让读者看出**谁该赢、为什么可能不赢**。
- 宗门大比、夺宝、追杀、秘境、复仇、装瞎示弱：每一种都依赖不同因素组合。
- 主角成长：若只有境界一条轴，中段必然注水；若因素太多且权重相近，读者记不住谁强。

所以本轮要回答的不是“这个世界有多少种能力”，而是：

1. 有哪几**类**东西能改胜负？
2. 哪几类要写成全书主引擎（反复抢、反复丢、反复被揭）？
3. 哪几类只作调味，免得重蹈第一本“设定先于情节”的问题？

## 二、六类因素

六类足够覆盖经典修仙的大多数戏，又不会一上来变成属性表。其他体系（暂不命名）可以对同一张表换皮，不必另造分类。

### 1. 位阶：门槛

**包括**：大境界；同境深浅（未定名）；刚破境不稳或旧伤未复。

**情节功能**：告诉读者“正常情况谁该赢”，制造压迫和升级欲望。

**典型戏**：卡在门槛外求机缘；渡劫或破境时被人偷袭；金丹在小界横着走；元婴一来，一城噤声。

**写作约束**：大境界不应被嘴炮、顿悟、无铺垫的友情光环打破。同境深浅可以翻，大境翻盘必须动用下面 3、4、5 类中的例外。

### 2. 本钱：人身上难改的底子

**包括**：资质 / 灵根一类的入口条件；根基是否扎实；神魂强弱；肉身抗打；剩余寿元。

**情节功能**：开局身份、改命、老怪拼命、针对神魂或肉身的阴招。

**典型戏**：资质差进不了内门；冒险改灵根或补根基；寿元将尽的金丹孤注一掷；神魂偷袭破掉“境界碾压”的表面优势。

**写作约束**：本钱适合当**起点和隐患**，不适合当每章讲解的表格。读者知道“这人底子差 / 底子厚 / 寿元不够”即可。具体分几品，下一轮再定。

### 3. 手段：可学、可夺、可残缺

**包括**：本命功法；攻伐术法 / 神通；实战经验与身法；有代价的秘术、禁术。

**情节功能**：同境对决的主要内容；传承争夺；克制；“会不会打”造成的意外。

**典型戏**：残篇拼图；同门偷功法；以克制破强敌；禁术翻盘后吐血、走火或留下标记。

**写作约束**：不要给每个大境界固定“一招成名神通”。手段按人物和传承走，读者跟的是**这个人会什么、缺什么**，不是境界说明书。

### 4. 外物：可抢、可毁、可耗尽

**包括**：法宝 / 灵器；丹药、符箓等一次性消耗；灵兽、傀儡；可带走的阵盘、禁制物。

**情节功能**：最适合写“抢”的一类。物件换手，势力关系就变。

**典型戏**：拍卖、夺宝、宝物认主、以器越阶、护身符挡下一死、灵兽反噬或被夺。

**写作约束**：外物可以让低境活过不该活过的一击，但应是**次数有限**或**目标太大引来更强的人**。否则人人一块神器，境界墙就塌了。

### 5. 场况：这一场才成立的条件

**包括**：地利、天时、灵气浓度；固定山门 / 秘境规则；当场伤势与灵力余量；人数与配合；情报与预谋；当场不许破的规矩（比武、圣地、同门不可开杀）。

**情节功能**：最适合写开篇、逃亡、围杀、比试。读者不需要新名词，只需要看见“地方不对、人太多、规矩捆着手”。

**典型戏**：在别人的阵里硬闯；秘境限境、限时、限杀；围杀高手；比武不能取性命，阴招因此更阴；情报差导致打错人。

**写作约束**：场况是情节的油，不是新体系。用一次就应改变下一场的条件（人受伤、阵破了、规矩被当众撕破）。

### 6. 因果与忌惮：长线钩子

**包括**：气运；仇怨与因果纠缠；身份背景（背后有人）；道心 / 心魔；上界或大界投下的影子（遗命、禁令、遗物主人）。

**情节功能**：解释“为什么强者不立刻打死弱者”，以及“赢了为什么更麻烦”。

**典型戏**：不敢杀气运之子；杀了某人引来其师尊；心魔在关键一击时发作；动了上界遗物，小界立刻不安宁。

**写作约束**：忌惮可以救人，但不能每场都靠“对方投鼠忌器”幸免。气运可以偏一点，不可写成无敌光环。上界阴影要稀、要贵、要惹祸，才能当续作接口而不抢本卷戏。

## 三、建议的权重：三硬、三软、一小界

种类可以有六，真正反复推动情节的不宜平均用力。建议本书这样压权重：

### 三硬（读者默认成立，几乎不用解释）

1. **位阶**：谁该怕谁。
2. **外物**：抢什么、丢什么。
3. **手段**：同境怎么打、传承为什么值钱。

这三硬构成经典修仙的阅读公约。开篇三章里至少要让读者看见其中两硬在打架。

### 三软（制造翻盘；每次必须有条件或代价）

4. **场况**：埋伏、秘境、规矩、围杀。
5. **消耗型外物与禁术**（外物和手段里的“一次性”子集）：翻盘后牌就没了。
6. **因果与忌惮**：赢了留下后患，强者不能为所欲为。

软因素负责“这一场为什么不是高境界直接碾死”，也负责章末钩子。

### 本钱：要有，但少讲

资质差、根基不稳、寿元将尽，用来定人物起点和个别孤注一掷，不做成贯穿全书的评分系统。第一本在“每境寿元数字 + 每境神通”上铺得太满，阅读上像在背设定。

### 小界专属的一硬（为舞台服务，不是第七套体系）

- 小界灵气与资源有上限，金丹已是豪强，元婴极少露面。
- 化神几乎只存在于“离去 / 传说 / 残骸”。
- 偶发的上界遗物或界外渗漏，属于**外物 + 因果**：能越阶，也必然把更大的猎人引进来。

这样本卷可以写“井中争霸”，又不必把大界修士请进来当常驻NPC。

## 四、一场能写的战斗，用什么配方

重要战斗建议固定成可读的三层，而不是把六类因素同时堆上：

```text
门槛差（谁该赢）
+ 当场变量（地利 / 人数 / 规矩 / 伤势，最多两个）
+ 一张有代价的牌（法宝、禁术、丹药、秘密身份）
```

胜负揭晓时，必须发生下面至少一件事，否则这场打完情节不前进：

- 一张牌用掉或被夺；
- 伤势、寿元或道心留下把柄；
- 身份、仇怨或宝物暴露，招来下一波人；
- 当场规矩被打破，势力关系改写。

这就是“情节最重”在战斗里的操作定义：**打完要少点东西，或多点麻烦。**

## 五、六类因素各自能养活的情节类型

下面不是大纲，只是核对：若某类戏我们想写，就该让对应因素在设定里真的有牙齿。

| 想写的戏 | 主要靠哪几类 | 若权重反了，会变成 |
|---|---|---|
| 开篇追杀 / 灭口 | 位阶压迫 + 场况（逃、藏、借地形）+ 一张保命外物 | 变成散步遇险，再插入大段身世 |
| 宗门大比 | 同境手段 + 有限外物 + 比试规矩 | 变成境界展示会 |
| 夺宝 / 拍卖 | 外物换手 + 忌惮（不敢当众抢）+ 事后追杀 | 变成逛街鉴定 |
| 秘境 | 场况规则 + 外物机缘 + 位阶限制谁能进 | 变成风景游记 |
| 越级反杀 | 禁术或神器 + 场况 + 事后代价 | 变成无铺垫觉醒 |
| 复仇 | 本钱或手段的长期积累 + 仇家忌惮变化 | 变成突然变强回来秒杀 |
| 示弱装瞎、打脸 | 隐藏手段或外物 + 对方按位阶误判 | 变成读者也莫名其妙的藏招 |
| 围杀老怪 | 人数配合 + 阵法场况 + 老怪禁术反扑 | 变成人海无脑堆 |
| 上界影子 | 遗物外物 + 因果忌惮 | 变成高人随便下场把小界剧情掐死 |

开篇抓人，优先选表中前四行那种**当场就能看懂利害**的戏，不要先选“文明路线之争”或“制度是否正义”。

## 六、相对第一本，明确降权的东西

这些不是不能写，而是**不再当胜负主轴**，以免开篇又要先上课：

| 第一本的主轴 | 第二本如何安置 |
|---|---|
| 名分 / 锡命决定力的合法性 | 最多写成场况：宗门规矩、不得擅杀、比武契约 |
| 仪轨走完才有全力 | 不作为通用施法流程；个别宗门可以有自家仪式，不当全书语法 |
| 血食供养网、贡道战略 | 小界可以有灵脉、灵矿、税赋，但是资源场况，不是主题技 |
| 每境一个标志神通 | 取消。神通跟人物走 |
| 问鼎式“质疑即削弱” | 不采用主题外挂。揭穿身份可以影响忌惮，不直接削伤害 |
| 会盟阵临时抬一大境 | 多人配合放在场况里，有限、可打断，不作为升级替代品 |

视觉和招式仍可以有辨识度，但辨识度来自**人物手段和外物**，不来自两套文明对照表。

## 七、其他体系怎么挂在这张表上

暂不命名。约定一句即可：

> 凡能在小界里动手的存在，都用同一套六类因素结算。差别只在本钱从哪来、手段长什么样、外物叫什么。

例如（仅示意，名称未定）：炼体强在本钱里的肉身；邪修强在禁术与外物献祭；妖类强在本钱与外物合一的本体。它们与人修冲突时，读者仍然先看境界对位，再看当场有没有牌、有没有场况。

这样以后补名称，不会推翻本轮分类。

## 八、对下一轮“等级区分”的接口

本轮不划档，只预留下一轮必须回答的切口，避免又做成九行大表：

| 因素 | 下一轮需要的，只是“主要档” | 不需要的 |
|---|---|---|
| 位阶 | 各大境界内部分几档、破境不稳怎么写 | 每境寿元精确年数、每境神通名 |
| 本钱 | 资质是否公开分品、神魂是否单独成阶 | 灵根元素克制网 |
| 手段 | 功法 / 术法是否分凡、灵、玄等常见档 | 全宗门技能树 |
| 外物 | 法宝分几档、消耗品是否另档 | 完整器谱 |
| 场况 | 秘境常见规则类型、山门阵是否分档 | 把阵法做成第二套修炼体系 |
| 因果 | 气运是否量化；上界遗物是否单独高于本界法宝 | 完整天道法则书 |

档次建议继续用读者熟的词，不另造难记的新阶名。

## 九、本轮拟采纳的结论（供拍板）

1. 战斗因素先分成六类：**位阶、本钱、手段、外物、场况、因果忌惮**。
2. 全书主引擎是三硬：**位阶、外物、手段**；翻盘靠三软：**场况、一次性牌、忌惮后患**。
3. 胜负总原则：大境是墙，墙内打牌，翻墙出血。
4. 重要战斗用“门槛差 + 当场变量 + 一张代价牌”，打完必须少东西或多麻烦。
5. 小界上限与上界遗物，当作舞台规则和外物，不单开体系。
6. 第一本的制度即战力，整组降权。

若这六条成立，下一轮再谈各因素的主要等级区分；地图、宗门和主角放在再下一轮，以免人物倒逼规则。
