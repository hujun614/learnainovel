# 总则与讨论顺序

> 讨论稿。未写入本文的细节，一律视为未定。

## 一、这一本要改的方向

`firstnovel` 的核心创意辨识度高，但朋友读后觉得情节抓人不够，开篇不能立刻产生追读欲。原因不只是文笔，而是**胜负逻辑前置了独特制度**：读者要先懂礼、巫、名分、贡道，战斗才好看。这适合慢热的文明对决，不适合“一上来就想看下文”的经典修仙阅读。

第二本改走经典套路，原则只有一句：

> **情节最重。设定为情节服务，不为展示世界服务。**

因此：

- 修仙大结构不求新奇，用读者一看就懂的凝气—化神。
- 世界做小：只写大界之下的一个小界，避免开篇摊开天下。
- 战斗因素要早定，因为**谁能赢、怎么翻盘、开篇写什么冲突、资源抢什么**，都由战斗因素决定。
- 等级区分、宗门升级法、其他体系名称，都排在战斗因素种类之后。

## 二、已定世界骨架

| 项 | 决定 |
|---|---|
| 舞台 | 修仙大界之下的一个小界 |
| 大界 / 上界 | 存在，但本卷只作压力、传闻、遗物和出口，不展开高等级战场 |
| 人修大等级 | 凝气（凡人—入门，引气）→ 练气（凡间中坚）→ 筑基（宗门骨干，正式踏仙道）→ 金丹（宗主、豪强，高阶起点）→ 元婴（一域霸主，常人不可及）→ 化神（传说；通常到不了，到了就要入上界） |
| 其他体系 | 大致可与上表对位；名称与细阶暂不设计 |
| 宗门升级差异 | 允许不同宗门在同一大等级上条件不同；暂不具体设计 |

小界的叙事作用（暂记，地理与势力下一轮再谈）：

- 天花板低，金丹已是一方豪强，元婴近乎传说，化神几乎只存在于古籍和上界方向。
- 灵气、灵矿、传承都稀，**抢**比**悟**更先推动情节。
- 上界遗物、界门、化神残骸，是“小池塘里突然出现大鱼”的合法来源，也是续作接口。

## 三、讨论顺序

1. **战斗因素种类**（本轮，见 `01`）  
   只问：一场冲突里，有哪些**类型**的东西能改变胜负，以及它们各自能生出什么情节。
2. **各因素的主要等级区分**（下一轮）  
   例如法宝分几档、功法分几档、同境深浅怎么叫。仍保持读者熟悉，不另造一套难记的名字。
3. **小界地理、势力、资源**  
   在战斗因素能解释“抢什么、怕什么”之后再画。
4. **主角、对手、开篇情节**  
   最后用已定因素去设计钩子，避免先定人物再倒逼规则。

## 四、本轮明确不做的事

- 不写每境神通表、寿元表、完整法宝名录。
- 不定其他体系（体修、魔修、妖修等）的正式名称。
- 不定各宗门破境仪式和资源清单。
- 不把第一本的“名分 / 仪轨 / 血食供养网即战力”搬过来当主轴。

制度、补给、仪式若出现，只作为**场况或外物**的一种（例如宗门比武规矩、护山大阵、一口灵泉），不作为读者必须先学会的胜负哲学。
