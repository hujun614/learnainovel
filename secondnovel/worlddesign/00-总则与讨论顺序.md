# 总则与讨论顺序

> 卷一正典：`04`～`07`、`09`。全书正典：`11`～`14`。`01`～`03` 为讨论底稿，`08` 为评审记录，冲突时以正典为准。  
> 开篇八章与卷一章序以 `09` 为准；全书格局以 `11` 为准。

## 一、这一本要改的方向

`firstnovel` 的核心创意辨识度高，但朋友读后觉得情节抓人不够。第二本改走经典套路：

> **情节最重。设定为情节服务，不为展示世界服务。**

开篇已锁：**苍州北地，沈家守黑水矿，夜遇流窜劫修。**

全书已升格（见 `11`）：

> **沈望川从南域边矿的三郎，成为苍澜界可见的顶级人物；沈家从南域守矿户，把本宅迁到中域天澜城。人的境界和家的地址必须同步涨。**

开篇三章已成稿，不推翻。苍州北地是第一截舞台，不是全书舞台。

## 二、已定世界骨架

| 项 | 决定 |
|---|---|
| 舞台 | 苍澜界全界。第一截只写南域苍州北地；南溟、天澜后置 |
| 地理 | 五域。南域矿多灵薄（起点）；中域灵脉密、籍最贵（终点）；东、西、北为情节入场 |
| 地址轨迹 | 青石坞 → 苍州城别院 → 南溟城沈府 → 天澜城本宅（祖宅仍留青石坞） |
| 大界 / 上界 | 传闻、遗物、出口；本书不打上界战场 |
| 人修大等级 | 凝气 → 练气 → 筑基 → 金丹 → 元婴 → 化神 |
| 同境 | 初期、中期、后期、圆满 |
| 功法 / 术法 / 法宝 | 黄 < 玄 < 地 < 天；可见上限天阶 |
| 见识差 | 边地以金丹为豪强、元婴为传说；那是边地见识。中域金丹满街，化神是小界天花板（三到五人） |
| 势力（真档） | 化神数人 > 中域三宗（衡云、赤霄、无相）+ 天澜朝 > 南溟宗 / 南域矿盟 > 北寒朝 > 铁石宗 > 沈家（边地户起） |
| 衡云宗 | 中域三宗之一；苍州中南部只是南域分院。开篇呈现不改 |
| 北寒朝 | 南域地方朝，治苍州。「北」是州内北方矿带，不是五域之北 |
| 隐世大宗 | 不入场。中域可有「空府」（籍去上界后留下的山门） |
| 前期格局 | 正规势力较稳。刀出在矿上和路上 |
| 中期变局 | 北寒与衡云南域分院争苍州矿权，中小洗牌；沈家进城 |
| 后期变局 | 入中域，开废脉，占天澜一席 |
| 男主家族 | 青石坞沈家。关起门来是一家。手艺是穿脉，不是打仗 |
| 男主私欲 | 开篇：族里那份筑基资粮。其后随地址升级，见 `13` |
| 双螺旋 | 人的境界 × 家的地址，每卷同步进一步 |
| 开篇 | 黑水矿守矿遇劫修。敌：厉铮一股。匣：旧矿图 + 《穿石锥》残拓 |

## 四、明确不做

- 不写每境神通表、寿元表、完整法宝名录。
- 不定其他体系正式名称、各宗门破境仪式清单。
- 隐世大宗、天阶之上、上界来人：不入场。化神：卷一至卷三不现身；卷六起可入场，不替沈家收尾。
- 不搬第一本的名分/仪轨/血食即战力。
- 开篇不灭门、不族内踩死男主、不对北寒或衡云宣战。
- 开篇不讲解五域、三宗、天澜朝。
- 不让望川弃族飞升；不把沈家写成背景板；终局占一席，不清空棋盘。
- 东、西、北三域不为观光入场。
