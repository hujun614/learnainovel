# 总则与讨论顺序

> `04`～`07` 为正典。`01`～`03` 为讨论底稿，冲突时以正典为准。

## 一、这一本要改的方向

`firstnovel` 的核心创意辨识度高，但朋友读后觉得情节抓人不够。第二本改走经典套路：

> **情节最重。设定为情节服务，不为展示世界服务。**

开篇已锁：**苍州北地，沈家守黑水矿，夜遇流窜劫修。**

## 二、已定世界骨架

| 项 | 决定 |
|---|---|
| 舞台 | 苍澜界；本书只写苍州北地 |
| 大界 / 上界 | 传闻、遗物、出口；不展开 |
| 人修大等级 | 凝气 → 练气 → 筑基 → 金丹 → 元婴 → 化神 |
| 同境 | 初期、中期、后期、圆满 |
| 功法 / 术法 / 法宝 | 黄 < 玄 < 地 < 天；可见上限天阶 |
| 势力 | 衡云宗（大宗门）> 北寒朝（中型，北地称朝）> 铁石宗（小宗门）；沈家、卫家；郝家作内斗对照 |
| 隐世大宗 | 不入场 |
| 前期格局 | 正规势力较稳。刀出在矿上和路上 |
| 后期变局 | 北寒朝与衡云宗争北地矿权，中小洗牌 |
| 男主家族 | 青石坞沈家。关起门来是一家 |
| 开篇 | 黑水矿守矿遇劫修。敌：厉铮一股。匣：旧矿图 + 地阶残拓 |

- 不写每境神通表、寿元表、完整法宝名录。
- 不定其他体系正式名称、各宗门破境仪式清单。
- 隐世大宗、天阶之上、化神、上界来人：不现身。
