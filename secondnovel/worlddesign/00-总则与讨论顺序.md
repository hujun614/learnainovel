# 总则与讨论顺序

> 讨论稿。未写入本文的细节，一律视为未定。

## 一、这一本要改的方向

`firstnovel` 的核心创意辨识度高，但朋友读后觉得情节抓人不够，开篇不能立刻产生追读欲。原因不只是文笔，而是**胜负逻辑前置了独特制度**：读者要先懂礼、巫、名分、贡道，战斗才好看。这适合慢热的文明对决，不适合“一上来就想看下文”的经典修仙阅读。

第二本改走经典套路，原则只有一句：

> **情节最重。设定为情节服务，不为展示世界服务。**

因此：

- 修仙大结构不求新奇，用读者一看就懂的凝气—化神。
- 世界做小：只写大界之下的一个小界，避免开篇摊开天下。
- 战斗因素要早定，因为**谁能赢、怎么翻盘、开篇写什么冲突、资源抢什么**，都由战斗因素决定。
- 功法、术法只用读者熟的黄、玄、地、天；势力用大宗门、中型宗门（有的地域称皇朝）、小宗门、家族、散修。隐世大宗仍不入场。
- 男主家关起门来是一家：可有内部矛盾，对外是一体。开篇惊险放在外派任务或驻地，敌对对象先是流窜劫修，不把自家开局写成灭门。

## 二、已定世界骨架

| 项 | 决定 |
|---|---|
| 舞台 | 修仙大界之下的一个小界 |
| 大界 / 上界 | 存在，但本卷只作压力、传闻、遗物和出口，不展开高等级战场 |
| 人修大等级 | 凝气（凡人—入门，引气）→ 练气（凡间中坚）→ 筑基（宗门骨干，正式踏仙道）→ 金丹（宗主、豪强，高阶起点）→ 元婴（一域霸主，常人不可及）→ 化神（传说；通常到不了，到了就要入上界） |
| 其他体系 | 大致可与上表对位；名称与细阶暂不设计 |
| 宗门升级差异 | 允许不同宗门在同一大等级上条件不同；暂不具体设计 |
| 势力阶梯（本书可见） | **大宗门 > 中型宗门（部分地域称皇朝）> 小宗门 > 散修**。家族与同级宗门结构相近，平均略低。 |
| 隐世大宗 | 世界里有，且高于大宗门，功法可在天阶之上。本书是起步，**暂不让隐世大宗及其功法入场**，只可作传闻或天花板。 |
| 功法 / 术法品阶 | 黄阶 < 玄阶 < 地阶 < 天阶。本书可见上限为天阶；天阶之上留给隐世大宗与后续作品。 |
| 前期格局 | 大宗门、中型宗门/皇朝、小宗门、各家族相对稳定。顶级势力要对峙，内部先求稳，因此不轻易吞并中小。 |
| 后期变局 | 国别（或同级大门派）对抗起来后，平衡被打破，中小势力重新洗牌。 |
| 男主家族 | 团结和睦为底色；有不同人物和内部矛盾，但关起门来是一家。 |
| 开篇冲突 | 外派任务或外派驻地；纠葛对象是流窜劫修。 |

小界的叙事作用（暂记，地理与势力细目下一轮再谈）：

- 天花板低，金丹已是一方豪强，元婴近乎传说，化神几乎只存在于古籍和上界方向。
- 灵气、灵矿、传承都稀，**抢**比**悟**更先推动情节。
- 上界遗物、界门、化神残骸，是“小池塘里突然出现大鱼”的合法来源，也是续作接口。
- 读者在小界里先认势力阶梯，再认个人强弱：看见“大宗门弟子”或“皇朝官差”就预期功法、术法、外物更好，看见“散修、劫修”就预期更杂、更狠、更没后援。打破这个预期，本身就是戏。
- 前期地图看起来太平，刀出在路上和驻地；后期国别一打，中小才重新洗牌。

## 三、讨论顺序

1. **战斗因素种类**（见 `01`）  
   一场冲突里有哪些类型的东西能改变胜负。功法、术法的大品阶已并入此类，不再当作完全空白。
2. **比较能抓住读者的情节类型**（见 `02`）  
   只谈类型与组合；开篇组合已按“外派遇劫修”改过。
3. **家族团结、稳世破局与感情线**（见 `03`）  
   讨论“不团结则败”是否成立，以及在此背景下情节与男主感情线怎么长。
4. **各因素尚未定的等级区分**  
   例如同境深浅怎么叫、法宝是否跟黄玄地天走、禁术代价分不分档。不另造难记的新阶名。
5. **小界地理、可见势力、资源**  
   在“抢什么、怕什么、开篇写哪类戏”清楚之后再画。隐世大宗仍不入场。
6. **主角、对手、开篇细纲**  
   最后用已定因素和情节类型去设计钩子。不锁姓名。

## 四、本轮明确不做的事

- 不写每境神通表、寿元表、完整法宝名录。
- 不定其他体系（体修、魔修、妖修等）的正式名称。
- 不定各宗门破境仪式和资源清单。
- 不让隐世大宗、天阶之上功法在本卷现身。
- 不把第一本的“名分 / 仪轨 / 血食供养网即战力”搬过来当主轴。
- 不把开篇写成家门被灭或族内踩死男主；前期也不让男主对大宗门/皇朝宣战。

制度、补给、仪式若出现，只作为**场况或外物**的一种（例如宗门比武规矩、护山大阵、一口灵泉），不作为读者必须先学会的胜负哲学。
