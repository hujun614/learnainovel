# 卷二·卷三情节纲要

> 卷一详纲见 `09`。本文按同一格式给后两卷骨架：主线、人物弧、必兑现、可调开关、情绪节拍。  
> 章数为预估，进入该卷前须先扩成逐章表。

# 第二卷 · 矿图

> 卷名：卷二·矿图  
> 章数：约 36 章  
> 境界：练气后期滞 → 卷中重续根基 → **卷末破筑基**  
> 内核：已经知道这不像流寇，还要不要装成只是流寇  
> 情绪：憋 → 查 → 更憋 → 一次破口  

## 一、卷主线（扩写版）

1. **两边伸手**：衡云带文书要买断黑水矿的胚料；北寒复核矿照。沈家夹在中间，两边都不能得罪。
2. **找后半**：望川的路只剩《穿石锥》后半。线索指向图上那处旧坑主人的记号。
3. **旧坑主人**：查出那桩北寒与衡云都不愿提的旧事——不揭全，只揭到“当年这条脉出过事，两边都埋了人”。
4. **石晚宁与绳子**：铁石宗的胚契约与亲事同时收紧。压望乔还是压望川，本卷必须给答案。
5. **郝家内斗**：一桩具体的事（争矿照、分灵脉、告到矿监衙），不是背景闲话。沈家看在眼里。
6. **江蘅的册子**：她被划掉的那一笔是谁划的。她可以走，她选择先不走。
7. **青桐的账**：赤铜坑的赔没算完，卫家内部开始有人主张“别跟沈家绑太死”。
8. **重续根基**：望川用一次代价极大的机会补回被禁术伤掉的根基。不是丹药天降，是拿别的东西换的。
9. **喊与不喊**：证据快够了。衡山仍按住。这一次望川第一次不完全服。
10. **破境**：筑基。发生在守住的人和找回的残篇上，不是闭关顿悟。
11. **卷末破口**：北寒与衡云不再默契。不是男主宣战，是矿权、买矿、清剿三件事同时变脸。

## 二、人物弧（卷二）

| 人 | 卷二要走的一步 |
|---|---|
| 望川 | 从“先扛后说”到“先说再扛”。破筑基。但他学会说话的同时，也学会了第一次对家里保留 |
| 望恒 | 拿了资粮却卡住，第一次尝到望川卡的滋味；兄弟关系真正和解 |
| 青桐 | 夹在卫家内部主张与沈家之间；她要自己拿一次主意 |
| 江蘅 | 来历揭到七分；她第一次为自己而不是为交易做一件事 |
| 衡山 | 从“按住”到“开始布置”。读者要看出他不是懦弱 |
| 衡海 | 伤好不全，退到二线；把外事交出去的过程要疼 |
| 望乔 | 承认自己可能一辈子破不了；转向做家里最会算账的人 |
| 石晚宁 | 从名字变成人；她自己也不想只当一根绳子 |
| 周启年 | 矿账压力见底；他要么倒向一边，要么被处理掉 |

## 三、必兑现（卷二）

- [ ] 望川破筑基，且方式与人和残篇有关
- [ ] 《穿石锥》后半找到或确认已毁（二选一，不能悬着到卷三）
- [ ] 旧坑主人的旧事揭到“两边都埋了人”这一层
- [ ] 郝家内斗具体事件落地
- [ ] 石晚宁出场并有自己的主张
- [ ] 江蘅来历揭到七分
- [ ] 望川第一次不完全服从衡山
- [ ] 卷末三件事同时变脸，天变了但战还没开

## 四、可调开关（卷二）

| 编号 | 开关 | 默认 | 可选 |
|---|---|---|---|
| L1 | 亲事压谁 | 压望乔，望川得以脱身但欠兄长 | 改压望川（则感情线三方同时紧张） |
| L2 | 《穿石锥》后半 | 找到，但要拿一样重要的东西换 | 改：确认已毁，望川自己补全（更难写，更有分量） |
| L3 | 望川重续根基的代价 | 用旧矿图的一部分情报跟人换 | 改：欠江蘅一个人情（则卷三她的选择更重） |
| L4 | 周启年结局 | 倒向一边，成为卷三的熟面孔 | 改：被灭口（则北寒的狠更早立起来） |

## 五、情绪节拍（卷二）

```
01–08  夹缝：两边伸手，谁也不能得罪
09–18  查：旧坑、册子、郝家；越查越不敢喊
19–26  收绳：亲事、赔账、卫家内部松动
27–32  换与补：拿东西换后半，重续根基
33–36  破口：破境；天变；战还没开
```

# 第三卷 · 站队

> 卷名：卷三·站队  
> 章数：约 40 章  
> 境界：筑基初期 → 卷末筑基中期  
> 内核：翻脸之后，站哪边、护哪些人、丢哪一块  
> 情绪：乱 → 割 → 立  

## 一、卷主线（扩写版）

1. **清剿默契停**：劫修不再被两边同时追。厉铮的余党或被收编成脏刀，或被灭到沈家门口。
2. **前线**：黑水矿从边矿变成前线。矿照还在，但守不守得住已经与照无关。
3. **家门被要**：战阵压境。这类戏到此才合理。
4. **郝家先散**：当面验证不团结则败。沈家看着，也看见自己可能的下场。
5. **卫家站队不同**：青桐夹在两户之间。感情线在这里碰到立场，不靠吃醋。
6. **铁石宗分裂**：有的升，有的附庸。石晚宁自己选一次。
7. **江蘅的局**：她被划掉的那一笔在这一卷有人来收。她的账收在她自己身上，不为望川洗白。
8. **三样账**：沈家必须付——丢一处驻地；有人担罪或死；一门亲事让出去或强留下来。
9. **望川的位置**：他不再只是守矿的子弟。但他打赢的仍是局，不是境界。
10. **新格局**：北地重新分。沈家还有一张椅子，椅子比从前小，也比从前稳。
11. **续作接口**：墨晶脉没挖完；所谓天阶只是误认的地阶残；衡云与北寒的伤不是这一代能结的；上界与隐世大宗仍只是传闻。

## 二、必兑现（卷三）

- [ ] 沈家付出至少三样可见的账，不写齐心无损
- [ ] 郝家先散，当面对照
- [ ] 卫家与沈家站队不同，且不靠误会解决
- [ ] 厉铮那句“还你一个籍”的许诺当面破灭一次
- [ ] 望川完成一次不靠境界的胜利
- [ ] 男主不弃族
- [ ] 结尾不拔高大境，不请隐世大宗下场

## 三、可调开关（卷三）

| 编号 | 开关 | 默认 | 可选 |
|---|---|---|---|
| M1 | 丢哪一处 | 黑水矿 | 改：赤铜坑（则卫家的账彻底翻转） |
| M2 | 谁担罪或死 | 望恒 | 改：衡海（更痛，但外事线要另找人接） |
| M3 | 亲事结局 | 让出去 | 改：强留（则铁石宗成为卷末新对手） |
| M4 | 青桐结局 | 进沈家成自己人 | 改：走而账清（更苦，也更贴“付钱”主题） |
| M5 | 江蘅结局 | 自己了断那笔册子的账，去留由她 | 改：留下但不入沈家籍 |

## 四、情绪节拍（卷三）

```
01–10  乱：默契停，前线成形
11–20  割：郝家散，卫家分，亲事逼
21–30  底：家门被要，三样账逐一付出
31–36  立：不靠境界的一次胜利
37–40  尾：新格局；小而稳的一张椅子；接口留着
```
