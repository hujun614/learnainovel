# 苍澜界全图

> 正典。全书地理、势力档位、资源与「地址=阶层」以本文为准。  
> 卷一可见的矿、镇、坞、功法细则仍见 `04`；本文管的是那张坞外面的界。  
> 开篇不把本文摊给读者。五域用走路、口音、文书、被人看不起的方式出现。

---

## 一、苍澜界是什么

修仙大界之下的一个完整小界。有海、有脉、有朝、有宗，够一个人从边矿走到化神，也够一户人家从南域迁到中域。

上界存在，路径是化神之后的出口、遗物、旧坑里的非人手凿痕。本书不打上界战场。已去上界的人留下的山门，边地叫「隐世」，中域叫「空府」——都是籍被抽走之后的房子。

界内常识（边地人不全知道，中域人当饭吃）：

- 灵气从中域向四域递减。中域养人，四域养矿、养兽、养遗坑。
- **籍**写在哪一级，人就是哪一级。矿照是最小的籍；天澜城的名籍是小界里最贵的一张纸。
- 完整天阶极稀。地阶完整、天阶残篇，已够中域三宗动手。

## 二、五域

不平均写。南域是前五卷的主场，中域是后三卷的主场。东、西、北为情节服务时才进去。

```text
            北域（苦寒、兵脉）
                  |
西（遗坑、秘境）—— 中域（天澜城）—— 东域（海商、岛链）
                  |
            南域（矿带、边荒）
                 苍州
              青石坞 / 黑水
```

### 1. 南域 · 起点

灵气薄于中域，矿却是五域里最密的。能活下来的中小势力，多半靠矿、靠税、靠替更大的势力看住一条路——这句话在 `04` 里已经成立，现在只明确：它说的是南域，不是整个苍澜界。

**苍州**是南域靠北的一州，矿最多，人也最土。州内再分：

| 地点 | 功能 | 阶层含义 |
|---|---|---|
| **青石坞** | 沈家祖宅、小灵脉一口 | 边地户的根。养不起金丹 |
| **黑水矿 / 黑水镇** | 玄铁、下脉墨晶砂；矿监衙 | 租来的照。守别人的矿 |
| **卫家赤铜坑** | 换料友族 | 比沈家更小的边户 |
| **铁石宗** | 小宗门，吃矿炼器 | 苍州这一档的「有山门的人」 |
| **苍州城** | 北寒朝在本州的治所、城中门阀 | 边地户第一次进城会被按身份口气 |

南域之都 **南溟城**：比苍州城高一档。南域大宗、南域矿盟、真正的金丹常驻。卷五沈府立在这里，等于南域承认沈家不是土户了。

南域其他州（开篇不点名，卷四按需取用）：沿海一州、靠近中域的「廊州」（入中必经）。廊州是卷四、卷六的过路戏台。

### 2. 中域 · 终点

灵脉密、宗门密、拍卖行和名籍衙门都在这里。中域不缺金丹，缺的是**新脉**和**还能用的旧脉**。灵脉已被占尽，废脉、封脉、被人埋掉的坑，才是真正的争夺。

**天澜城**：小界最繁荣的城。天澜朝坐镇，三宗各有城中府，拍卖、大比、名籍都在此处。卷八沈家本宅迁到这里，才叫走到了中心。

**衡云山**：衡云宗山门，中域境内。苍州中南部那一处，只是南域分院——买矿、收胚、看边。卷一里「衡云外门来买矿」说的就是分院的人；真正山门的人，口音和文书都会不一样。

中域另有二宗、若干部小宗、若干世家。名单在第四节，随卷展开，不在开篇报幕。

### 3. 东域

海、岛链、散修和商会比宗门多。适合写：海路矿料、一桩买脉的商盟、一个没有朝只有会的对照。望川若要在中域买下一席，钱和料往往从东域走一遭。不作为长期主场。

### 4. 西域

古修遗坑、妖兽、场况怪异的秘境。适合写：穿石锥的源流残页、旧坑主人真正的来路、化神遗物。秘境限境规则仍是场况，不是第二套修炼。不作为长期主场。

### 5. 北域

苦寒、兵脉、另一路称「朝」的势力。适合写：与南域北寒朝不同的治军气味、一卷的外敌或一度的盟友。不把北域写成「北寒朝的老家」——北寒朝就在南域苍州，名字里的「北」是苍州内部的北方，不是五域的北域。

## 三、地名对照（防止写岔）

| 边地人怎么叫 | 实际是 | 何时让读者知道 |
|---|---|---|
| 北地 | 苍州靠北的矿带，相对苍州城而言 | 卷一即用，不必纠正 |
| 南边大宗 | 衡云南域分院，或更往北的中域 | 卷二三用口音和文书让人起疑；卷五正面揭 |
| 朝 | 北寒朝。边地人以为朝就是天 | 卷四进南溟城，才看见南域还有更大的治所 |
| 上界 | 化神之后的去处；也用来骂人「做白日梦」 | 卷六以前只闲话 |

**北寒朝的「北」**不要解释成五域之北。它是南域苍州的地方朝，因州内北方矿带得名。中域人会把它叫「南边那家朝」，这句轻蔑本身就是打脸原料。

## 四、势力（全书档位）

卷一表见 `04`。下表是同一批名字在全图上的真档，以及后文才露面的档。

### 1. 开篇已有，档位升格

| 名称 | 卷一读者看到的 | 全图真档 | 后文 |
|---|---|---|---|
| **衡云宗** | 苍州中南部大宗门，北地只闻其名，外门来买矿 | **中域三宗之一**。苍州中南部是南域分院 | 矿权之争的一极；卷六起是中域的天，也是必须平视的对手 |
| **北寒朝** | 北地一主，收矿税、发矿照、派矿监 | **南域地方朝**，治苍州及周边 | 卷二三与衡云争南域矿权；卷五后可能缩成藩、裂、或被沈家在南域取代一角 |
| **铁石宗** | 黑水东南小宗门 | 苍州档。有山门，仍是土宗 | 联姻绳子；南域洗牌时有的升、有的附庸 |
| **沈家** | 青石坞守矿户 | 边地户 → 南域名门 → 中域世家 | 地址轨迹见 `11` 第七节 |
| **卫家** | 友族，赤铜坑 | 始终比沈家小半档的友族 | 卷三可能站队不同；南域阶段可再绑，中域未必跟得上 |
| **郝家** | 邻族对照 | 内斗户 | 卷三当面散掉；后文可用另一户换皮重复「不团结则败」 |
| **流窜劫修** | 开篇敌 | 秩序外。后期被喂、被收编、被灭口 | 气味不换；卷六中域也有更干净的「脏刀」 |

### 2. 卷一以后才正面的

| 名称 | 档 | 出场 | 功能 |
|---|---|---|---|
| **南溟宗** | 南域大宗（低于中域三宗） | 卷四 | 南域的天。大比、名额、看不起苍州土户 |
| **南域矿盟** | 商/族联合，不是宗门 | 卷四～五 | 沈家手艺的买方。入盟比拜宗更贴穿脉事业 |
| **天澜朝** | 中域皇朝，与三宗同档两套皮 | 卷五文书，卷六正面 | 名籍衙门在它手上。沈家迁天澜城，籍要过它这一关 |
| **衡云宗**（山门） | 中域三宗之一 | 卷六 | 开篇那股买矿的气味的老家 |
| **赤霄宗** | 中域三宗之一，偏丹与灵植 | 卷六 | 另一极。可与衡云互忌 |
| **无相楼** | 中域三宗之一，偏神识、册籍、情报 | 卷六，江蘅的册子可能指向这里 | 给「籍」这门功课一个具体的庙 |
| **天澜城诸世家** | 金丹～元婴世家 | 卷六～八 | 看不起南域来的人；其中一户会把废脉「赏」给沈家当诱饵 |
| **化神散人 / 化神坐镇** | 小界三到五人 | 卷六传闻，卷七～八入场 | 天花板。不替沈家收尾，是终局必须平视或绕开的人 |

隐世大宗仍不入场。中域的「空府」可以给一座：山门还在，籍已经去了上界。那是化神之路的镜子，不是外挂援军。

## 五、资源：什么东西能让人搬家

前期抢的是车、照、匣、资粮——`04` 已锁。全图上，抢的东西要换档，但气味仍是「脉」。

| 阶段 | 抢什么 | 为什么能换地址 |
|---|---|---|
| 边地 | 玄铁、矿照面子、封石匣、筑基资粮 | 活下来，被苍州看见 |
| 苍州洗牌 | 墨晶脉解释权、新照 | 进城，有别院 |
| 南域 | 南域矿盟一席、一口能养金丹的脉、大比名额 | 南溟城立府 |
| 入中 | 中域废脉的开凿权、天阶残、东域的钱与料 | 借住变成有名无实的「客」 |
| 中域中心 | 一口真正能写进天澜名籍的灵脉山、化神相关的出口遗物 | 本宅迁天澜城 |

**墨晶砂**的价：边地用来养地阶胚；中域用来养脉眼、续废脉。沈家开篇没弄清的价，就是后来能进中域的通行证。不要开篇讲这个，让中域来人的开价把读者吓一跳。

**《穿石锥》**：术法是单攻，事业是穿脉。后半若只当更强的锥子，家族迁不进中域；后半必须让人看见「这一锥能打开一口别人打不开的脉」。

## 六、地图使用规则（防观光）

1. **新域只在情节需要时开门。** 望川为找后半、为买脉、为救一个人、为躲一场灭口，才进新域。不为「该去西域看看了」而走。
2. **每进一档地理，先挨一次看不起，再打一次脸，再付一次搬家的账。** 三拍缺一，这档就是旅游。
3. **旧地图不废。** 青石坞、黑水矿、苍州城在后文仍要回来：祖宅、旧仇、旧照、不愿迁的族老。家往中心走，根还在南域。
4. **北寒与衡云的矿权之争**，在全图上是「南域地方朝 × 中域分院」的代理战。真正的中域三宗本体，卷五以前不下场开战。这样卷一「不对大宗门宣战」仍然成立。
