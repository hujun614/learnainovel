# 第一卷情节纲要 · 卷一总览与人物互动矩阵

> 书名暂定：《穿石》  
> 卷名：卷一·黑水  
> 章数：32 章  
> 境界：练气后期 →（伤根基）→ 练气后期滞 → 卷末仍未破筑基  
> 内核：守住眼前的人，才发现有更大的一笔账；知道了，却还不能喊  
> 情绪：绷紧 → 失去 → 微光 → 更重的压 → 憋住  

本文是卷一的全局纲要。前八章的逐章施工另见 `07-开篇细纲.md`，两者冲突以本文的章序为准。

---

## 一、卷主线（扩写版）

1. **守矿日常**：望川主事黑水矿；下脉挖出封石匣；那份筑基资粮压在三个人头上；望恒抢功已有酸话。
2. **夜袭**：流窜劫修厉铮要匣不要铁；沈石死；三才阵合不上；望川开禁术逼退圆满，赔进自己今年的破境把握（硬伤 B 首次兑现）。
3. **一夜之后**：江蘅开价；青桐算铜料的赔；矿监周启年按册问责；对外一张嘴，匣的事关门吵。
4. **那杆秤被点破**：家书里提资粮；望乔卡圆满三年；望恒的抢功有了正当动机；望川不肯承认自己也在争（硬伤 C 首次露头）。
5. **一线与反打**：残拓练出一线地阶威力；西谷夜袭反打，斩厉铮副手、夺回拓角（本卷第一处获得）。
6. **判断失误**：望川选择守矿、让衡海押匣回坞；空库钓不到人，反而暴露匣已上路；山路截击，衡海受伤，图的一半被撕走（硬伤 B 的代价，本卷最大一次失败）。
7. **坞中的秤**：回青石坞；衡山、望乔正面出场；伤根基的事瞒不住（硬伤 A 被当众戳破）；族议第一次摆资粮。
8. **借不借人**：卫家赤铜坑被咬；沈家关门吵；望川自订期限迟了半日，铜坑死人（硬伤 B 再兑现）；青桐不原谅，仍并肩。
9. **走岔与半个身世**：穿石锥用得太狠，第一次真走岔；江蘅在救与不救之间选了救，并说出一半来历。
10. **西谷与厉铮的价**：清剿；第一次看见真正的战阵；厉铮说出他要的是一个籍；灭口的人到，望川选择救活口而非泄愤（成长）。
11. **知道了，不能喊**：戟纹指向暗账；望川想喊，衡山按住。
12. **卷末债**：族议定资粮；望川失了先手，功摆在那里；他的路只剩残篇后半。喘息一顿饭。衡云的人再来，卷二到期。

## 二、本卷重要人物卡（互动用）

### 沈望川（主）

- **欲**：挣下那份筑基资粮；守满这一届；让死掉的人不白死。
- **惧**：成为家里的累赘；亲手把兄弟的路挤掉；发现自己也变成只会先扛后说的人。
- **本卷弧**：从“把事扛住” → “扛不住也得说” → “知道有更大的账，却只能憋着”。境界没涨，人长了。
- **硬伤**：
  - **A｜先扛后说**：伤、匣、残拓、根基，一律先自己担着。伤的是最信他的人。
  - **B｜先救眼前人**：为看得见的人放弃更大的账。第02章丢库，第09～12章丢图，第18章迟援。
  - **C｜不肯承认自己也在争**：明明想要资粮，偏说“我只是尽责”。望恒因此觉得他虚伪，这一条卷末才被戳穿。
- **本卷兑现**：A 三次（伤、残拓、根基）；B 三次（矿道、押匣、铜坑）；C 一次（第31章族议）。

### 沈望恒（堂兄）

- **欲**：那份资粮；被叔父和族里正眼看一次。
- **惧**：一辈子被当成“冲得快但不稳”的那个。
- **本卷弧**：抢功 → 被望川挡在功劳外而记恨 → 铜坑迟援时他其实主张早走（这次他对）→ 卷末拿到资粮，却发现望川没跟他争过面子。
- **互动功能**：证明“内部矛盾”不必靠坏人。他和望川要的是同一样东西，谁都不坏。

### 卫青桐（友族·战友线）

- **欲**：卫家的铜料路走通；被当成能商量事的人，不是被保护的人。
- **惧**：两户绑在一起，赔的总是小的那户。
- **本卷弧**：并肩 → 算赔 → 迟援之怒 → 仍然回来并肩，但话说得比刀更硬。
- **互动功能**：戳破硬伤 A 的第一人（“你要是早说，我能带人”）。

### 江蘅（劫修相关·身份会炸）

- **欲**：活着，并且不再被谁记在册子上。
- **惧**：再被当成一件有用的东西转手。
- **本卷弧**：被裹来识矿 → 开价 → 观望 → 在望川走岔时选择救 → 说出一半来历，仍不交底。
- **互动功能**：她是唯一不欠沈家、也不怕沈家的人，因此能说所有人不敢说的话。

### 沈衡海（叔父·管外事）

- **欲**：把矿保住，把两个小的保住。
- **惧**：自己撑不住时没人接得上。
- **本卷弧**：迟到 → 骂人补防 → 押匣受伤 → 卷末仍替望川在族议上说一句话。
- **互动功能**：**硬伤 A 的家族镜像**。他也是先扛后说的人。望川在他身上看见自己，这比任何说教都有力。

### 沈衡山（家主）

- **欲**：沈家在北地还有一张椅子。
- **惧**：这一代分不匀，家从里面裂。
- **互动功能**：按住想喊的人。他不是不明白，是知道喊了会死。

### 沈望乔（长兄·准家主）

- **欲**：破了那道坎，别再让族里为他为难。
- **惧**：耗到最后，资粮给了他也没成，还耽误了弟弟。
- **本卷弧**：护弟 → 主动提让 → 被望川拒绝 → 卷末反过来支持给望恒。
- **互动功能**：让“资粮给谁”成为真两难，而不是给主角开路。

### 厉铮（开篇敌）

- **欲**：拿匣换一个籍，回到有门有派的世界。
- **惧**：像条野狗一样死在没人记得的地方。
- **本卷弧**：夜袭 → 缠 → 被反打 → 说出他的价 → 被灭口。
- **互动功能**：本书公理的反面教材。没有所属的人怎么活、怎么死。他要可恨，也要可怜。

### 周启年（北寒矿监）

- **欲**：把北地矿账交代过去，保住自己的位子。
- **惧**：上面查到他头上。
- **互动功能**：让读者觉得烦，而不是觉得他是反派。真正的反派本卷不出场。

## 四、分章纲要（32 章）

### 第一幕｜黑水一夜（01–08）

逐章细节见 `07-开篇细纲.md`。

| 章 | 事件 | 落点 |
|---|---|---|
| 01 | 匣回营，夜袭起 | 望川的欲被点出 |
| 02 | 矿道逼退厉铮 | 越级的爽 + 伤根基 |
| 03 | 活人与开价 | 沈石死；江蘅谈条件 |
| 04 | 矿监与两笔账 | 罚、限期、铜料赔 |
| 05 | 家书与那杆秤 | 资粮之争点破 |
| 06 | 一线 | **获得一** |
| 07 | 反打 | **获得二**：斩副手、夺拓角 |
| 08 | 图角 | 望川选守矿，衡海押匣 |

### 第二幕｜押匣与坞里的秤（09–14）

- **09 空库**：厉铮扑空。但空库反证匣已上路——望川自以为的钓局，成了给对方的情报。他第一次尝到“自作聪明”的滋味。
- **10 急报**：山路截击。衡海重伤，护匣队死伤，**旧矿图被撕走一半**。望川在矿上收到消息的那一刻，明白自己该去的是山路。
- **11 追**：带伤追。青桐同去，江蘅指近路（她要一个新条件）。望恒留守——他不服，但他守住了。
- **12 半夺**：夺回衡海和匣身，图没追回来。本卷最重的一次失败。厉铮那句“你们守的东西，我拿了一半”留到卷末回响。
- **13 青石坞**：第一次正面写沈家家宅。衡山、望乔出场。灵脉、族田、议事厅，用一顿饭和一次交接带出，不摊开讲家史。
- **14 族议（一）**：伤根基的事被族医说破（硬伤 A 当众破功）。望乔提出把资粮让给望川；望川当场拒绝。望恒的功被记下。第一次摆秤，不作结论。

### 第三幕｜借人与走岔（15–22）

- **15 黑水镇**：衡云买矿的人久留不走。江蘅认得那个人的口音，只说了半句。周启年也在盯他。
- **16 铜坑告急**：赤铜坑被小股劫修咬。青桐要回去，沈家要不要借人。
- **17 关门吵**：本卷“团结必要而不充分”的第一次考验。望恒主张立刻走；望川主张先把矿上的口子补完再走。衡海伤着说不上话。**这一次望恒是对的。**
- **18 迟了半日**：望川自订期限，晚了半日到铜坑。死了人。他救下的那几个，换不回来晚到的那几个（硬伤 B 第三次兑现，也是最疼的一次）。
- **19 赔**：两户之间的账。青桐当面骂他：你要是早说你伤成那样，我能带人。硬伤 A 被最信他的人戳破。
- **20 石晚宁**：铁石宗来人，提胚契约与亲事。压望乔还是压望川，本章不定，但两家都知道绳子收紧了。
- **21 走岔**：连日用穿石锥，残篇没有后半，第一次真走岔。经脉伤上加伤，人几乎废在矿道里。
- **22 半个来历**：江蘅本可以走，她留下救了他。醒来后她说出一半：她曾被记在某处的册子上，被划掉了。不说是哪处。**第二印象“她是人”在此落地。**

### 第四幕｜西谷与厉铮的价（23–30）

- **23 限期**：周启年逼到最后一日。北寒查矿账的压力压到他身上，他也在赌。
- **24 西谷（一）**：清剿开始。北寒镇军的战阵第一次出现在望川眼前——他第一次直观看见“真正的组织”是什么样，而沈家只有三才阵。
- **25 西谷（二）**：厉铮的窝。找到的不是金银，是他攒了多年的、想拿去换籍的东西。
- **26 厉铮的价**：正面对话。他说出他要什么：一个籍，一处能写自己名字的地方。望川第一次觉得敌人可怜——**本书公理在这里落地**。
- **27 灭口**：有人不想厉铮活着说话。来的人干净、利落，不是流寇的手法。
- **28 救不救**：望川选择救活口，而不是趁乱报沈石的仇。这是他本卷唯一一次把更大的账放在眼前的人之上——成长。
- **29 死与话**：厉铮仍死了，留下一句话和戟上的纹。他到死也没等到那个籍。
- **30 空口**：纹指向暗账。望川想喊，衡山按住：喊了，沈家明天就没了。第一次尝到“知道了却不能说”。

### 第五幕｜卷末（31–32）

- **31 族议（二）**：资粮定给望恒——他涨得快、最可能成。望川因伤根基失了先手。望乔投的是望恒。望恒拿到后反而说不出话，因为望川从头到尾没跟他争过一句面子。**望川的硬伤 C 在这里被望恒当面戳穿**：你要是早认你也想要，我至少输得明白。望川无话可答。
- **32 一顿饭**：矿营的喘息章。青桐要回赤铜坑，账没算完；江蘅留下，仍不认恩；望恒别扭地把半块饼推过来。望川的路只剩残篇后半。**章末**：衡云的人第二次到黑水镇，这次带了文书；北寒的矿照复核也下来了。两边同时伸手——卷二到期。

## 八、卷二·卷三纲要接口

详见 `10-卷二卷三纲要.md`。此处只记卷一交出去的东西：

- **人**：衡海伤着；望恒拿了资粮；青桐带着没算完的账回赤铜坑；江蘅留下，来历只说了一半。
- **物**：匣身在坞，图丢了一半；残拓仍缺后半；戟纹指向暗账。
- **局**：厉铮死了但那股气味没断；衡云带文书来了；北寒要复核矿照；铁石宗的亲事绳子收紧。
- **人物欠账**：望川承认了自己在争，却已经没有资粮；他往下走只有一条路——找《穿石锥》后半。
