# 全书八卷纲要

> 正典。全书三截八卷：边矿 → 南域 → 中域。  
> 卷一详纲仍是 `09`；卷二三骨架仍是 `10`，卷末接口按本文加大一号。  
> 卷四及以后进入该卷前须扩成逐章表。章数为预估。

---

## 总表

| 截 | 卷 | 卷名 | 主场 | 望川境界 | 沈家地址 / 籍 | 内核 |
|---|---|---|---|---|---|---|
| 边矿 | 一 | 黑水 | 黑水矿、青石坞 | 练气后期滞 | 祖宅 + 租来的照 | 守住眼前的人，发现更大的账，却还不能喊 |
| 边矿 | 二 | 矿图 | 苍州北地 | 重续 → **破筑基** | 深脉解释权萌芽 | 知道不像流寇，还要不要装成只是流寇 |
| 边矿 | 三 | 站队 | 苍州洗牌 | 筑基初 → 中 | **苍州城别院** | 翻脸之后站哪边、护谁、丢哪一块 |
| 南域 | 四 | 南溟 | 苍州城 → 南溟城 | 筑基后 → **金丹** | 人在南溟走动 | 土户进城，手艺第一次为南域所用 |
| 南域 | 五 | 立府 | 南溟城 | 金丹 | **南溟城沈府**；青石坞改祖宅 | 名门不是打出来的，是立住的 |
| 中域 | 六 | 入中 | 廊州 → 中域 | 金丹后 → **元婴** | 中域借住 / 客院 | 南域名门在中域仍是土户 |
| 中域 | 七 | 开脉 | 中域废脉、三宗之间 | 元婴 | **中域一口灵脉山** | 打开别人打不开的脉，才配谈籍 |
| 中域 | 八 | 天澜 | 天澜城 | **化神** | **天澜城沈府**为本宅 | 从要籍的人，变成发籍的人 |

三截的气味不断档：

```text
边矿：劫修要匣，不像抢铁
南域：匣上的脉对上南域的盟和中域的料场，土户被叫进都城
中域：废脉、弃籍、空府，同一股「没有地址的人怎么活」的气味，换成小界中心的地板
```

不要中途换一套不相干的终极反派。可以换脸、换主使，不要换气味。

# 第一截 · 边矿（卷一～卷三）

现有 `09`、`10` 继续作为施工正典。下面只写**必须加大的接口**，不重写 32 章。

## 卷三卷末改一号（相对 `10`）

旧终局：北地重新分，沈家还有一张小而稳的椅子。  
**新终局**：椅子仍要付钱才能坐，但坐的是**苍州城别院**，不是继续缩在青石坞。

- 丢掉黑水矿或赤铜坑其中一处（`10` 的 M1 仍有效）——丢掉的那一处，换成城里的一席；
- 有人担罪或死（建议望恒担罪、重伤，不死，见 `13`）；
- 一门亲事让出去或强留下来；
- 墨晶脉的解释权至少留下一角，作为卷四进南溟的见面礼；
- 衡云分院与北寒朝的伤不是这一代能在苍州结的——上面还有南溟和中域。

续作接口从「上界传闻」改为两层：南溟城来了一封请帖或一张矿盟的帖；江蘅的册子上出现中域的印。上界仍只是闲话。

卷二三必兑现维持 `10`。追加一条：**卷三结束时，沈家在苍州城必须有一处能住人的别院**，哪怕是借的、典的、联姻带过来的。没有这一席，卷四「土户进城」没有台阶。

# 第二截 · 南域（卷四～卷五）

## 第四卷 · 南溟

> 章数：约 40 章  
> 境界：筑基中后期 → **卷末金丹**  
> 内核：土户进都城；手艺第一次不是为了守自己的矿  
> 情绪：小 → 被看轻 → 打脸 → 更小（看见南溟还有天）

### 卷主线

1. **进城。** 苍州城别院住不下要办的事。南溟城来帖：矿盟、南溟宗外门、或一桩南域都城才有的拍卖。沈家关门吵：去不去、谁去、祖宅谁守。
2. **看不起。** 南溟宗真传或矿盟执事按地址口气。打脸发生在门外（大比、拍卖、验脉），家里不踩。
3. **手艺上市。** 一口南域废脉 / 封口，别人打不开。望川用穿石锥（此时应已有后半或自己补全的路）打开一线。打开不是高潮，是通缉令：南溟宗、矿盟、北寒残余、衡云分院同时伸手。
4. **大比或秘境。** 同境硬仗，兑现沉路对南域快功法。快的真赢几场。
5. **江蘅可以走。** 都城的册开始问她。她留下或先走后返，须是她的选择。
6. **青桐拿主意。** 卫家跟不进南溟。她选：跟沈家走，或把卫家留在苍州当根与眼。
7. **破金丹。** 发生在打开的脉和守住的人上，不是南溟宗赐丹。
8. **卷末。** 南溟城看见沈家了，但立府的地契还没有。真正的名门差一张纸。衡山仍按住：纸要望乔去要，不要望川去抢。

### 人物弧（卷四）

| 人 | 这一卷走的一步 |
|---|---|
| 望川 | 硬伤 C 变形：第一次当众说「我要南溟承认」。金丹 |
| 望乔 | 在都城文书上第一次赢。读者看见没他脉会从纸上滑走 |
| 望恒 | 土阵进都城挨笑，再在一场围杀里打出牙齿 |
| 青桐 | 自己拿一次地址的主意 |
| 江蘅 | 都城有人来问册；她为自己选一次去留 |
| 衡山 | 可以开始想「我不去都城」——祖宅的影子 |

### 必兑现（卷四）

- [ ] 进南溟城之前，先在苍州城挨一次「边地户」的看不起
- [ ] 穿脉手艺为南域所用，当场惹出比边地更大的伸手
- [ ] 南溟真传至少赢望川一场，再在关键场输掉
- [ ] 青桐完成一次地址选择
- [ ] 望川破金丹，与脉和人有关
- [ ] 硬伤 A/B/C 各兑现一次南域形态
- [ ] 卷末有「看见了名门，还没有府」的缺口

### 可调开关（卷四）

| 编号 | 开关 | 默认 | 可选 |
|---|---|---|---|
| N1 | 进城的帖从哪来 | 南域矿盟请验脉 | 改：南溟宗外门名额（则拜宗压力更大，须防弃籍） |
| N2 | 打开的那口脉归谁 | 沈家得一线解释权，大头仍被盟/宗按住 | 改：全归沈家（则卷五立府太容易） |
| N3 | 青桐是否随行 | 随行，但卫家本宅留苍州 | 改：她留苍州（战友线变书信，齿会弱一截） |

## 第五卷 · 立府

> 章数：约 40 章  
> 境界：金丹（可到金丹中后期，不破元婴）  
> 内核：名门是立住的，不是打赢一场就搬进去的  
> 情绪：筹 → 裂 → 立 → 天外有天（中域文书到了）

### 卷主线

1. **立府要三样：** 一口能养金丹的脉（或矿盟一席）、一张南域承认的名籍、一座南溟城的宅。三样各是一条线，不要一场拍卖全买齐。
2. **望乔主场。** 联姻、税、名籍衙门、对南溟宗的客卿约。望川在外护脉、挡刀，府是望乔立的。
3. **衡山留守。** 青石坞改祖宅。本宅名义迁南溟，根留边地。族里有人不愿迁——关起门来吵，对外仍是一家。
4. **石晚宁的绳子收完。** 亲事有结论。她本卷后可以退出主舞台。
5. **北寒朝的下场。** 缩藩、内裂、或把苍州矿权的一角让给新名门。周启年若还活着，在都城变得很小。
6. **郝家公理换皮。** 南溟城一户内斗名门先散，沈家看见「到了都城也会从里面裂」。
7. **立府那一天。** 清点活人。能坐下的、空着的位子，都要写。
8. **卷末中域伸手。** 不是宣战。是廊州来的执事、一张废脉图、或江蘅册子上的中域印被活人对上。南域的天被揭开：上面还有天澜。

### 必兑现（卷五）

- [ ] 南溟城沈府立住，三样里至少两样是付了账换来的
- [ ] 望乔在文书和联姻上赢一次不可替代的局
- [ ] 衡山留守祖宅，搬家不是全族搬空
- [ ] 石晚宁线收束
- [ ] 一户都城对照因内斗而败
- [ ] 立府日清点活人
- [ ] 卷末中域接口落地，望川仍未破元婴

### 可调开关（卷五）

| 编号 | 开关 | 默认 | 可选 |
|---|---|---|---|
| N4 | 名籍怎么来 | 矿盟一席换南域名门籍 | 改：客卿南溟宗但不入籍（更贴「籍写沈家」） |
| N5 | 北寒朝结局 | 缩成苍州藩，沈家不再受它的矿监骂 | 改：裂掉（则南域真空更大，卷六前要补秩序） |

# 第三截 · 中域（卷六～卷八）

## 第六卷 · 入中

> 章数：约 44 章  
> 境界：金丹后期 → **卷末元婴**  
> 内核：南域名门，到中域仍是土户  
> 情绪：大 → 被按回去 → 怒 → 第一次看见废脉

### 卷主线

1. **过廊州。** 入中必经。中域执事的口气把「南溟沈府」叫成南边来的。打脸可以有，第一场不要对三宗宣战。
2. **天澜城 / 衡云山门外。** 拍卖、验籍、客院。沈家没有中域名籍，住客栈或借住都是屈辱，也是阶层课。
3. **江蘅的册子正面。** 无相楼或天澜朝弃籍。她的账自己了。望川可以帮，不能替她洗白成沈家的人。
4. **废脉诱饵。** 某世家或某宗把一口打不开的废脉丢给沈家。开了，他们来收；开不开，沈家当众丢人。
5. **三宗第一次作为本体出场。** 衡云山门的人，让读者把卷一买矿的外门对上老家。赤霄、无相各露一口牙。
6. **破元婴。** 发生在废脉一线和几乎被收走的局里，不是天澜朝赐爵。
7. **卷末。** 脉还没开完，籍还没有。沈家在中域只有客院。真正的开脉留给卷七——本卷只让读者相信：这口脉是他们唯一的路。

### 必兑现（卷六）

- [ ] 入中第一旬必有一次按地址的轻蔑
- [ ] 江蘅弃籍揭到可收束的一层（可留尾巴到卷八，不可再「只说一半」）
- [ ] 废脉诱饵落地，沈家接或不接都要付钱
- [ ] 衡云山门与卷一外门对得上
- [ ] 望川破元婴，与脉和局有关
- [ ] 硬伤 A 中域形态：对家里人瞒过一次底牌，被望乔或青桐戳破

## 第七卷 · 开脉

> 章数：约 44 章  
> 境界：元婴（可到元婴后期，不破化神）  
> 内核：打开别人打不开的脉，才配谈中域的籍  
> 情绪：开 → 抢 → 围 → 脉落在自己名下

### 卷主线

1. **开脉是事业高潮，不是单挑高潮。** 望川的锥、江蘅的识、望恒的阵、望乔的文书，四根同时上。缺一根，脉开了也会被收走。
2. **三宗与天澜朝同时伸手。** 沈家关起门来站队，对外一块。站错边会丢脉；不站会被当脏刀。
3. **化神的影子入场。** 不出手灭沈家，只让读者感到墙。或许这口废脉当年是某位化神封的。
4. **内斗对照。** 天澜城一户世家为抢脉从里面裂。郝家公理的最高换皮。
5. **打赢的是局。** 允许一场关键斩将，不允许望川一人屠宗。
6. **脉落沈家名下。** 中域灵脉山写上沈姓。这是天澜城本宅的经济凭证，还不是本宅本身。
7. **卷末。** 化神之路的出口/遗物从脉底露出来。上界仍不来人。望川看见天花板，知道金丹那年以为的豪强是什么笑话。

### 必兑现（卷七）

- [ ] 开脉必须四根梁同时在场（江蘅若已走，则识矿这根要有替代，且付出过找替代的代价）
- [ ] 中域灵脉山落到沈家名下
- [ ] 化神入场但不收尾
- [ ] 望川打赢的是局
- [ ] 一户中域对照因内斗而败
- [ ] 硬伤 B 中域形态：为眼前人几乎把脉丢了，再抢回来或认下来

## 第八卷 · 天澜

> 章数：约 40 章  
> 境界：元婴后期 → **化神**  
> 内核：从要籍的人，变成发籍的人  
> 情绪：迁 → 巅 → 对照 → 立（不是清空棋盘）

### 卷主线

1. **迁本宅。** 天澜城沈府。清点活人。青石坞祖宅仍在，衡山或族老守根。两张椅子。
2. **化神。** 与脉底的出口/遗物、与守住的人有关。不是吞了上界丹。化神之后仍是沈家的人。
3. **小界三到五位化神并存。** 他成为其中之一。有人平视，有人要收他当客，有人要他滚回南边。
4. **求籍者上门。** 厉铮的回声。望川接或拒，必须让读者想起西谷那句「要一个籍」。他现在是能给人籍的人——给不给，是终局性格，不是福利发放。
5. **江蘅的局收在她自己账上。** 去留由她。不入沈家籍也可以是圆满。
6. **青桐的地址。** 进天澜成自己人，或走而账清，或卫家仍在苍州当沈家的眼。三选一，在细纲里锁，但必须是立场不是吃醋。
7. **新格局。** 沈家本宅在天澜城，祖宅在青石坞，南溟府可以改分府。中域三宗还在，天澜朝还在。沈家占住一席，不清空棋盘。
8. **续作接口。** 上界出口可见，不进去。天阶仍是残。某一位化神已经在出口那一侧留下空府。本书打完的是小界的籍，不是上界的天。

### 必兑现（卷八）

- [ ] 天澜城沈府立为本宅；祖宅仍在
- [ ] 望川化神，不弃族
- [ ] 求籍者对照落地
- [ ] 感情线碰到地址，有结论，不弃族
- [ ] 终局是占一席，不是灭三宗灭朝
- [ ] 上界只作出口，不来人收尾
- [ ] 最后一次清点活人，能让读者看见卷一矿营那一顿的回声

### 可调开关（卷八）

| 编号 | 开关 | 默认 | 可选 |
|---|---|---|---|
| P1 | 化神人数 | 连望川在内四人，他最年轻 | 改：三人（更孤，更像厉铮，须用家族把孤压住） |
| P2 | 求籍者是谁 | 厉铮余党之后 | 改：一个与江蘅同类的弃籍者 |
| P3 | 青桐结局 | 卫家留苍州，她往来两地，账清，人是沈家的 | 改：走而账清 / 全迁天澜（后者卫家容易变随员） |

## 获得节拍（全书仍防只有失去）

约每三章一次可见的获得。档位变了，获得的种类跟着变，不能到中域还只斩劫修副手。

| 截 | 「拿到」长什么样 |
|---|---|
| 边矿 | 一线术法、斩对手、夺残页、族议认功、破筑基 |
| 南域 | 打开一口脉、大比名次、矿盟一席、立府的地契、金丹 |
| 中域 | 废脉一线、元婴、脉山名籍、天澜宅契、化神、一次给人籍或拒人籍 |

拿到之后立刻加码新麻烦。搬家本身算一次获得，搬家当晚必须有新麻烦进门。

## 与旧三卷文档怎么共存

- 写卷一：不要把南溟、天澜写进正文讲解。按 `09` 写，按 `11` 第八节埋接口。
- 写卷二三：按 `10`，把卷末椅子改成苍州城别院，把江蘅册子的方向锁向中域。
- 写卷四前：先把本卷扩成逐章表，再动正文。
- `06` 的宏观三卷仍然是第一截的正确描述，不再是全书描述。
