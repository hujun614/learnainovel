## 已定框架

- 舞台：苍澜界五域。起点南域苍州边矿，终点中域天澜城。上界只作出口与遗物。
- 双螺旋：望川的境界与沈家的地址必须同步涨。祖宅可留青石坞，本宅迁走。
- 事业：沈家靠穿脉（识石、开废脉），打仗是护手艺。
- 修炼：凝气 → 练气 → 筑基 → 金丹 → 元婴 → 化神。同境：初 / 中 / 后 / 圆满。边地见识不等于小界事实。
- 功法、术法、法宝：黄 < 玄 < 地 < 天。
- 势力真档：中域三宗（衡云、赤霄、无相）+ 天澜朝 > 南溟宗 > 北寒朝 > 铁石宗 > 边地沈家。衡云在苍州只有分院；北寒是南域地方朝。
- 前期正规势力较稳；苍州洗牌在卷三；入中域在卷六。
- 男主沈望川，沈家次子，开篇练气后期。关起门来是一家。开篇要的是族里那份筑基资粮，其后欲随地址升级。
- 开篇敌：流窜劫修厉铮。钩子：封石匣（旧矿图 + 《穿石锥》残拓）。
- 终局：化神之一，天澜城本宅，能给人籍。占一席，不清空棋盘。
