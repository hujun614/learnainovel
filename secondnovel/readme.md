## 已定框架

- 地点：苍澜界 · 苍州北地。更高世界留给后续作品。
- 修炼：凝气 → 练气 → 筑基 → 金丹 → 元婴 → 化神。同境：初 / 中 / 后 / 圆满。
- 功法、术法、法宝：黄 < 玄 < 地 < 天。
- 势力：衡云宗 > 北寒朝 > 铁石宗；沈家守黑水矿；卫家为友族。
- 前期正规势力较稳；后期北寒与衡云争矿权，中小洗牌。
- 男主沈望川，沈家次子，练气后期。关起门来是一家。他自己要的是族里那份筑基资粮。
- 开篇敌：流窜劫修厉铮。钩子：封石匣（旧矿图 + 《穿石锥》残拓）。
