# secondnovel

第二本小说：经典修仙套路、以情节为重。场景是修仙大界之下的一个小界。

与 `firstnovel` 分开维护，不沿用礼巫制度战、名分即战力、仪轨即战术等设定。

## 当前阶段

先讨论世界骨架与抓人情节类型，再进入地图、人物与细纲。

开始阅读请先看：

1. `worlddesign/00-总则与讨论顺序.md`
2. `worlddesign/01-战斗因素种类.md`
3. `worlddesign/02-吸引读者的情节类型.md`

## 已定框架（极简）

- 地点：修仙大界下的一个小界；更高世界与更高境界留给后续作品。
- 修炼大等级：凝气 → 练气 → 筑基 → 金丹 → 元婴 → 化神。
- 化神：传说级。通常到不了；到了就要（或才能）进入上界。
- 势力可见阶梯：大宗门 > 小宗门 > 散修；家族平均略低于同级宗门。隐世大宗更高，本书不入场。
- 功法、术法品阶：黄阶 < 玄阶 < 地阶 < 天阶。本书可见上限为天阶。
- 其他体系可与此对位，名称暂不设计。
- 各宗门在不同大等级的升级方式、条件可以不同，暂不具体设计。
