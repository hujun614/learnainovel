## 已定框架（极简）

- 题材：重生年代，都市商战。
- 主角 2026 年 46 岁去世，重生回 1997 年秋的高三，1998 年高考。
- 家乡：中部地级市，父母所在的万人重机厂正在改制。
- 主线五段：摆脱家庭经济危机 → 用个人能力小有收益、让家里看到经济前景 → 与青梅一起学习、考上不错的 985 → 高考后暑假开始创业 → 大学 → 进入社会。
- 感情：高三青梅，大一三人纠葛，大二校花，女主是大二出场的学妹；要写婚姻与孩子。
- 产业终局：不靠人多、员工能长出去、无负债、分散投资。
