# 主角前世与金手指边界

> 讨论稿。用户已定：前世约 40 岁，二本毕业，做过技术（前期靠维修赚钱）、跑过销售（真懂市场）、做过互联网公司中层后被裁。技术偏硬，好切入；赚钱大势只懂一部分；有了启动资金后保底能力强。

## 一、前世履历（推敲后的版本）

主角约 1980 年生，1997 年秋读高三，前世在 2020 年前后、40 岁左右重生。

| 前世时间 | 经历 | 今生能用的东西 |
|---|---|---|
| 1980 年代末—1997 | 工人子弟，从小在厂里电工房、家电修理铺边上长大，会拆收音机、修电视 | 解释他高三就能上手维修，前世基础就在这里 |
| 1997—1998 | 高三遇家里出事（父母下岗、父亲担保欠债），成绩下滑，高考失利 | 遗憾一：没护住家；遗憾二：没考好 |
| 1998—2002 | 读本省二本，电子信息类专业 | 电路、单片机、焊接，课本知识扎实 |
| 2002—2006 | **技术**：南方电子厂做维修和测试工程师；修过 CRT 电视、VCD/DVD、电脑、早期手机 | 维修手艺、懂元器件和成本、懂工厂怎么开模和量产 |
| 2006—2012 | **销售**：手机与数码配件的渠道销售，跑过省、市两级代理和电脑城 | 懂渠道、账期、回款、压货，知道东西是怎么卖出去的 |
| 2012—2020 | **互联网**：电商公司、后转本地生活平台做中层，带过供应链与地推团队 | 懂流量、补贴战、融资节奏和大厂打法；见过“站队”站错的公司死掉 |
| 2020 前后 | 公司裁员，人到中年失业 | 重生的情感起点 |

**推敲**：用户原定“技术 → 销售 → 互联网中层”，本版只补了两处。

- 前世的技术活放在南方电子厂，同时管维修和测试。这样他既能修，也懂**量产**。后面“产品生产 + 专利卖给企业”这条线，就有了前世经验作支撑。
- 前世做过渠道销售，卖的正是手机配件。这让他第一个产品选在手机配件上显得自然，见 `04` 第三节。

## 二、他记得什么

| 记忆强度 | 内容 | 用法 |
|---|---|---|
| 清楚 | 亲身经历：家里哪天出事、谁借过钱、厂子哪年改制；自己干过的行业里哪些东西爆过、哪些死过 | 家庭危机提前布局；产品选型 |
| 清楚 | 人尽皆知的大事：互联网泡沫 2000 年破、非典、入世、网吧火灾整顿、房价长期上涨、2007 年牛市见顶、2008 年金融危机、移动互联网和智能手机大潮 | 大周期判断，决定进退 |
| 模糊 | 股市具体点位、个股走势；哪家公司哪年融资多少钱 | 只做大周期，不做神操作 |
| 不知道 | 高考题、彩票号码、具体比赛比分 | 杜绝“背答案”式的爽，高考要真学 |
| 会失效 | 他一插手，身边的小事就会变（蝴蝶效应）；越往后，大事的细节也会偏离 | 中后期制造意外，防止全书只是照着记忆走 |

## 三、金手指边界（写作硬规则草案）

1. **只有记忆和手艺，没有系统。**
2. **记忆给方向，不给结果。** 他知道某个赛道会火，但产品、团队、钱、时机都得自己挣，而且会失败。
3. **技术是入场券，市场是护城河。** 每次切入新行业，都先靠一门硬技术或真实的渠道理解站住脚，不能凭“我知道它会火”空手套白狼。
4. **保底能力强。** 用户特别强调这一点。主角有钱后先留生活和家里的底，再去冒险。他从不 all-in，这正是中年人和少年人的区别，也是他和同龄对手拉开差距的地方。
5. **中年人的心智要有代价。** 他看同龄人像看孩子，这在大学感情线里会变成问题（见 `03`），不能写成纯优势。
