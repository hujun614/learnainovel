# 主角前世与金手指边界

> 讨论稿，第二轮。本轮把用户给的建议落成正典条目，标“已定”的不再讨论。
>
> 年份按 `01` 推荐 B 采用：**1997 年秋重生，1998 年 7 月高考。**

## 一、前世履历（已定骨架，细节可调）

| 时间 | 年龄 | 前世经历 |
|---|---|---|
| 1980 年 | 0 | 出生在中部某地级市，父母同在一家万人国企 |
| 1998 年 | 18 | 高考。家里正还债，母亲早点摊起早贪黑，他考得一般，上了本省一所二本 |
| 2002 年 | 22 | 毕业。跑建材销售、做过电脑城柜台 |
| 2008 年 | 28 | 进互联网公司做运营，赶上移动互联网 |
| 2011 年 | 31 | 结婚。两人都想“先买房、先升职，孩子再等等” |
| 2014—2025 年 | 34—45 | 升到运营中层，带三十来人的团队。2019 年协议离婚，**无子女**，没有争财产，此后很少联系 |
| 2026 年 | 46 | 公司用智能体工作流替换整条运营线，他的团队被裁撤。秋天回老家，老厂区要拆了，最后一次开放参观。夜里在老宿舍楼心梗，醒来在 1997 年 |

**感情包袱：几乎为零（已定）。**

- 前妻：好聚好散，没有孩子，没有怨恨。他重生后不用“赎罪”，也不用“回去找谁”。
- 青梅：前世她**没有选他**。不是错过，也不是失散，是她选了别人。他认过这件事，难受过，后来放下了。所以今生他对青梅的第一反应是“这次我能帮她”，不是“这次我要得到她”。这条决定了大一那段纠葛的走向，见 `04`。
- 唯一的硬遗憾是**家**：父亲那笔担保债拖垮了家，母亲 2003 年查出病时已是晚期，2005 年走了。

**他是谁**：不是大佬，是一个见过行业起落、懂人情、懂流程、被时代淘汰过一次的中年人。他知道“被技术替换”是什么滋味，这条直接决定了他后期怎么布局产业，见 `06`。

## 二、2026 年的 AI 趋势（只带一下，作前世背景）

主角死在 2026 年秋。他脑子里那年的世界，只在回忆、对比和后期布局时露一两句，不写成科普。

| 他记得的 2026 | 在书里的用处 |
|---|---|
| 大模型已经是水电一样的东西，写代码、写方案、做客服、做报表，大部分交给智能体 | 他被裁的直接原因。前世心结：“我会的那些，机器一夜之间全会了” |
| 被替换最快的不是工人，是**按流程干活的白领**：运营、客服、外包、初级程序员 | 后期他做产业，不把护城河建在“人多”上 |
| 人形机器人和工业自动化进厂试点，算力和电力成了新的硬约束 | 后期投资方向的远景，只作为“他知道终点、不知道路线”的模糊记忆 |
| 靠人海堆规模、靠贷款扩张的公司，在技术换代时死得最快 | `06` 的总原则来源 |
| 他知道的未来**到 2026 年为止** | 信息差有保质期。书写到后期，他必须为“2026 年以后我也不知道”做准备 |

写法：最多一个场景一句，比如他看着网吧里三十台电脑，想到的是“三十年后一个人加一个模型，就能干一层楼的活”。

## 三、重生优势：四样，各有边界（已定）

### 1. 记忆

只记得**大势**和**自己亲历的事**。具体日期、价格、考题，大多模糊。记错一次，书里要让他吃一次亏。

### 2. 学习方法：领先近三十年的“怎么学”

他前世没用过，是 2010 年以后在职场、育儿号、知识付费里反复见过。1997 年的高中还停留在“多做题、抄笔记、熬夜”。

| 方法 | 1997 年的叫法（他自己起的） | 用在谁身上 |
|---|---|---|
| 主动回忆、合上书默写框架 | “闭卷过一遍” | 青梅：把“看懂了”变成“写得出” |
| 间隔重复 | “三一七复习表”（第 1、3、7 天复看） | 青梅、自己 |
| 错题按“错因”分类，不按章节 | “错题病历本” | 青梅、寒门同学 |
| 题型建模，一类题一个母题 | “母题本” | 寒门同学，后来做成学习资料卖钱 |
| 讲给别人听 | “当小老师” | 主角给青梅讲，青梅给后排讲 |
| 考试策略：分段得分、先保后冲、按分值分配时间 | “抢分表” | 全班，班主任后来拿去用 |
| 睡眠、晨跑、午睡二十分钟 | 无，被老师当成“偷懒” | 自己。和第五条身体线合并 |

**效果（已定）**：青梅从年级三十名左右稳进前十，冲进好学校；主角自己从中游爬到 985 线。方法不是魔法，要让读者看到他们真的在做题。

### 3. 两道难题的方向记忆（已定）

**来源**：前世高考，寒门同学离最好的学府只差几分，丢分就丢在一道物理压轴和一道数学压轴上。二十年后同学会，寒门同学已是研究所的高工，喝了酒，在餐巾纸上给主角画那道物理题，说“后来才想明白，那其实是一道老题的拓展，多了一个条件”；又顺口讲了那道数学题的放缩思路。主角当时只是听着，觉得心酸，所以记住了。

**他记得的**：两道题的**题型和拓展方向**。物理一道，数学一道。

**他不记得的**：原题、数字、图。

**今生怎么用**：

- 高三下学期，他把这两个方向当作“我觉得会考”的专题，和寒门同学一起反复推演，青梅也跟着做。
- 他讲不出解法，只能讲方向；真正把拓展推透的是寒门同学。功劳归寒门同学，这是人物线的关键。
- 高考考场上，题目和他记得的**近似但不相同**，寒门同学靠推透的那层拓展做出来。主角自己只拿到一部分分。

**边界**：书中高考题为虚构，不对照真实试卷，不写成“泄题”。这两道题只在高考那一章兑现一次，不再复用。

### 4. 技术趋势：知道终点，也知道哪条路走得通

他知道宽带会取代拨号、手机会取代电脑、哪种技术路线最后赢了。他**不会**写代码、画电路。

规则：

- 他知道“哪条路走得通”，所以能少走弯路，**不知道路上每块石头**。
- 难题要靠人解决。他的手段是**找对人、给对条件、守住方向**：寒门同学、老家杰出校友、大学里的老师和学长，后期是自己培养起来的团队。
- 每解决一个主要难题，要让读者看到一个具体的人在熬夜。主角是那个知道该往哪挖的人，不是挖的人。

### 5. 巨头发展时机：投得比较准

用户要求：投资关键趋势公司的股票、入股公司，判断比较准确。这条覆盖 `00` 里“主角不投、不抢巨头”的旧默认，改为**投而不抢**。

| 规则 | 说明 |
|---|---|
| 二级市场可用真实公司 | 买的是公开上市的股票，时间、涨跌以史实为准，只作背景，不让真实企业家出场 |
| 一级市场入股用虚构公司 | 原型可以看得出，名字、创始人、细节虚构 |
| 只拿少数股权 | 不控股、不进董事会抢话语权、不改写巨头的命运 |
| 渠道是门槛 | 1990 年代个人买港股、美股很难。前期只能做 A 股和 B 股（2001 年 B 股对境内居民开放），后期靠公司和合法渠道 |
| 钱是门槛 | 高三上只有几千块，不碰股市。暑假以后才有本金 |
| 越碰越不准 | 他亲手碰过的小公司，命运会被他改变，记忆失效。大巨头离他远，反而准 |
| 每卷至少错一次 | 记错时间、被套、错过一次。准是“比较准”，不是全知 |
| 2026 年后归零 | 他的判断只到 2026 年。后期必须靠体系，不靠记忆，见 `06` |

### 6. 身体：想练好，但从不拼打架（已定）

- 前世心梗死的，所以他今生**第一件小事是晨跑**，戒掉前世熬夜、喝酒、久坐的习惯。体能线贯穿全书，写成“他比同龄人更能熬住”，不写成能打。
- **打架从来不拼**。遇到冲突，按这个顺序解决：撤离 → 找证人 → 报警或找组织 → 谈判 → 用规则让对方付代价。
- 可以挨一次打，不还手，把这一下变成对方的把柄。可以有朋友比他能打，但书里不靠朋友打赢。
- 禁止一打多、禁止“前世练过”的设定。
