# novelrules · 商周礼巫长篇创作规约

> **用途**：本文件是 `firstnovel` 的第一创作入口。写任何正文、扩写细纲或新增设定前，必须先读本文。
>
> **正典范围**：本文件、`readme.MD` 与 `worlddesign/00`～`10`。
>
> **基本原则**：本文只规定读取顺序、裁决方式和创作红线；具体设定仍以对应正典文件为准，不在此重复维护。

## 四、不可违背的主题规则

1. **礼巫同源，不是种族正邪**。巫修曾有燎、瘗、沉等可维系文明的路径；太乙朝的问题是四祭废三、独尊血祭。
2. **礼胜巫靠文明模式，而非主角战力**。可传承、可协作、允许退出且受公开程序约束的秩序，最终压倒依赖血食与强迫供养的速成体系。
3. **终局只有两条主因**：
   - 外部断供：截玄鸟道、毁祭坛、策反血食产地；
   - 内部改祀：苏鸢使国祭导向空祀。
4. 饕餮失控是断供后的后果；姬彝只提供残缺知识；玄鸟城因供养崩塌与守军哗变而开。三者都不是独立胜负按钮。
5. **新秩序并不完美**。卷五必须保留程序垄断、伪锡命、边地不满与话语僵化的隐忧。
6. 借鉴武王伐纣只取母题，不复制人物结局和战争节奏。子珏作为凡人存活、苏鸢不以死亡完成角色、祝由形成第三极，均不得回退。

## 五、世界运行硬规则

### 神学

- **上帝**：巫系血食网顶端、可贿可饲且越来越饥饿的神格。
- **天**：礼系不可贿的法则位格，只响应秩序是否真正成立。
- **命**：谁有资格解释统治、祭祀与秩序；祀籍、盟书、锡命都是其现实载体。

僭帝争上帝之位；承天与定鼎承接天。两者不得混写。

### 三层名分

| 名分 | 来源 | 主要效力 |
|---|---|---|
| 私名 | 师承、宗族、个人誓约 | 明礼～正心，不产生政治权柄 |
| 邦名 | 国君、宗庙、治下承祀与功绩 | 定序～匡道及问鼎一、五鼎；离邦衰减 |
| 天下名 | 太史寮原始祀籍 + 诸侯会盟 | 问鼎七鼎以上、承天、定鼎 |

突破不是闭关结果。功绩只是前提，授器、宣册、见证、承责完成后，力量才落定。

### 问鼎轻重

每次使用都必须写清：

1. 被质疑的是哪一项可验证的名实不符；
2. 证据来自祀籍、承祀实况还是合法礼器；
3. 对方是否用移祭、假祀、篡籍或胁迫承祀反制；
4. 若判断错误，主角承受何种锡命损伤或失鼎后果。

它只影响借名分、祀权或血食网导流的力量；对肉身、虫蛊、无主凶物和失控饕餮纹无效。

### 会盟阵

- 至少三方有效邦名；
- 盟书必须写明权责与退出条款；
- 钟、尊、合法主器缺一不可；
- 最多临时提升一个大境，不能跨过天下名门槛；
- 被打断会反噬所有参与者邦名；
- 强迫合祭会异化为血食掠夺。

### 供养网

- 人牲/流巫供国祭；
- 奄国血玉供储魂、血契与祭坛；
- 岐姒铜料、陶范供礼器；
- 各国祀籍副本供太史寮认证。

玄鸟道、沉牲渊、荆铜山是不可随意删除或改名的基础地理锚点。

## 六、人物写作规则

### 姬无咎

- 资质普通，成长必须与名分、联盟和责任绑定。
- 外温和、内执拗，不擅官场辞令；礼数较真可制造轻松感，但必须至少一次造成战机或人命代价，不能只作萌点。
- **格物辨形**只辨器物、祭法和仪轨，不读心。
- **母系血脉**只对为尸、借体产生生理反应，强用会诱发自身失控。
- **獬**只对公开言行中的名实矛盾示警，对沉默、纯暴力或真心作恶者无效。
- 暗探临岐时十一岁，獬已养两年；四年后进入青年阶段。

### 辛荼 / 蘅

- 同一人物的巫名与礼名；祀籍与牌位分别记名。
- 原为掌祝辞的女祝和尊贵尸位，不是泛称巫女。
- 只切断一支血契，不能单独给主角完整的天下断供战略。

### 姜续

- 权谋至少一次产生可验证的短期收益，主角不能永远正确。
- 奄国暗线救人但催化清洗；降卒宽释保住多数人却造成小部复叛。
- 终局不是姜续皈依主角，而是两人互相修正。

### 苏鸢

- 宫廷女祝，核心能力是祝辞、卜辞转译和国祭名序，不写成魅惑型宠妃。
- 她是受害者也是共谋者，倒戈前必须承担错误选择的后果。
- 终局执行改祀，代价是巫力、记忆与身份；不得复刻母亲自绝或默认死亡。

### 子珏

- 曾恢复三祭、限制血祭；改革失败和大卜子瞻被清洗是堕落起点。
- 不是天生暴君，也不能用悲惨过去免除责任。
- 终局失去的是血食共主身份，作为凡人存活。

### 姬彝

- 是有局限的历史证人，不是全知祖师。
- 卷三末交残缺镇纹，终局只补关键一笔后力竭。
- 同源往事分散呈现，不得在战场上整章讲解。

### 姒清、史牧、姬祝

- 姒清是邦名担保人，必须有主角不在场也能改变局势的政治决定。
- 史牧的原始祀籍直接参与问鼎和改祀，不是背景文官。
- 姬祝掌告祖、祝辞与程序记录，无感情线；她使礼修制度权力不只由男性角色掌握。

## 七、叙事与章节规范

- 默认第三人称限知，贴近当章视角人物；不得在主角不可能知道时直接解释敌方动机。
- 单章参考 3000～4000 字，但以完整戏剧单元为先。
- 每章须有一个核心问题，结尾的答案或新问题必须推动下一章。
- 新名词每章原则上不超过三个；优先用动作、器物和程序展示设定，少用旁白讲表格。
- 卷一母亲线持续推进，不写“开篇钩子后暂停数章”；“废柴受轻视”只能作短场景。
- 卷三主高潮是太史寮文书战；崇国只主力败退。
- 卷四主高潮是断供与改祀同步完成；不得恢复“牺牲—祖师救场—破城”三连。
- 卷五是短尾声，冲突围绕伪锡命与程序垄断，不重复大型战争。

### 优先爽点

1. **名分战**：揭伪锡命、会盟认证、原始祀籍翻案。
2. **补给战**：截贡道、夺沉牲渊、毁祭坛、争血玉。
3. **合祭战**：保留退出权仍自愿共担。
4. **辨形战**：从器仪破绽调查出身份，而非一眼辨奸。
5. **仪轨战**：简礼抢时、大礼易断、改祀争名序。

少写纯闭关、数值碾压、临场觉醒和无制度背景的越级胜利。

## 八、语言与文风

### 总体

- 文言韵味与现代可读性并重，叙述以白描和具体感官为主。
- 对话略古即可，不堆生僻字，不使用网络梗、游戏术语和现代职场比喻。
- 人牲与血祭写压迫、选择和后果，不以酷刑细节猎奇。

### 礼修

- 施法按**具—祝—献**。
- 祝词以四言为主，取《诗》《书》式庄重语感。
- 战场披甲默认肃拜；凶拜只用于送祟、镇丧、尸疫。
- 视觉为青铜绿、玄、暖金、几何纹路、钟磬与秩序共鸣。

### 巫修

- 施法按**祭—舞—降**。
- 卜辞短促、命令式、交易式，可用“贞：……可乎？”。
- 燎、瘗、沉三祭须与血祭呈现不同气质，不能把所有巫修都写成疯魔血祭者。
- 视觉为血雾、烟火、土石、水影、兽面与低语，随祭法变化。

### 祝由

- 不依礼仪，也不献祭通神，直接利用虫蛊、尸瘴、药脉和生命规律。
- 语言近民间歌谣或短咒，强调交换和实用。
- 不是中立就等于无立场，其底线是禁地自治与互惠。

## 九、战斗与仪式写法

写前依次确认：

1. 双方境界与合法名分；
2. 神通与招式是否对应；
3. 法印、巫舞、祭法与场合是否匹配；
4. 法器规格是否符合持有者身份；
5. 胜负由哪项制度条件改变。

每场重要战斗至少写出以下三项：

- 施法流程；
- 法印、巫舞或祭法；
- 声音与视觉标志；
- 明确代价；
- 名分、贡道、祭品、器物规格中的一个制度细节。

越阶取胜只允许来自会盟、断供、证据、地形、情报或对手自身代价，不允许无铺垫爆种。

## 十、历史概念转化规则

1. 史实提供概念骨架，玄幻机制负责戏剧功能；不能只换名称。
2. **尸不等于人牲**：尸原为尊贵受祭位，降格为人牲体现制度堕落。
3. **锡命是他者公开册命**，不是私人升级按钮。
4. 一鼎是取得问鼎资格的文学改造，不等同真实士三鼎；内部统一即可，正文不作学术讲座。
5. 格物、正心属于后世学宫对姬彝初制的层累解释，卷五可质疑其僵化。
6. 新增商周概念前先查 `00`～`05`；尚无定义时先补正典，再写正文。

## 十一、逐章创作流程

### 开章前

1. 读 `09` 当章和相邻章。
2. 写下一句“本章要迫使谁在什么之间作选择？”
3. 列出必出人物、地点、境界、法器、伏笔与章末状态。
4. 按第二节读取最小文件集。
5. 核对时间线与前章遗留伤势、物品、信息差。

### 起草时

1. 前五百字建立异常、欲望或阻碍。
2. 场景必须改变人物关系、信息、资源或名分中的至少一项。
3. 对话遵守 `07` 的角色语言差异。
4. 战斗和仪式遵守 `01`、`04`、`05`。
5. 章末状态须能自然进入下一章，而非另起随机悬念。

### 写完后

1. 对照 `09` 检查是否偏离章功能。
2. 检查人物是否使用了越界能力。
3. 检查新规则是否已存在于正典。
4. 若剧情改动合理但超出细纲，先回写 `09` 再定稿。
5. 更新 `03` 中的写作进度或待定问题。

## 十二、章后自检

### 正典

- [ ] 境界、名分、神通、招式、法印名称一致。
- [ ] 人物身份、年龄、能力和关系没有越界。
- [ ] 地点、贡道、资源与势力立场符合 `02`。
- [ ] 本章没有临时增加神器、境界或万能反制。

### 主题

- [ ] 胜负或成长至少与名分、联盟、供养、仪轨之一有关。
- [ ] 礼修不是天然正确，巫修不是天然邪恶。
- [ ] 集体行动保留个体退出与承担责任，不把礼写成温和强迫。
- [ ] 主角不是唯一能作出有效决定的人。

### 人物

- [ ] 姬无咎没有读心或一眼辨奸。
- [ ] 姜续的权谋不是永远错误。
- [ ] 女性角色不只承担牺牲、魅惑或情感安定功能。
- [ ] 角色说话方式可以彼此区分。

### 文风与读者体验

- [ ] 前五百字存在张力。
- [ ] 新名词数量可控，设定通过场景呈现。
- [ ] 礼、巫、祝由的动作与语言风格可直接辨认。
- [ ] 章末改变了局势或提出了必答问题。

## 十三、文档维护

- 本文件保持精炼，只记录跨文件创作规则，不复制完整设定表。
- 每次正典大改后，检查本文第二、三、五、六节是否需要同步。
- `03` 只记录完成度；任何新增正典必须落入 `00`～`10` 的对应文件。
- 正文文件建立后，应在 `03` 登记进度，并在本文件第二节补充正文目录规则。
