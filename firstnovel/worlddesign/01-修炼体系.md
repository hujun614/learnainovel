# 修炼体系：礼修 与 巫修

## 〇、术语与能力层级

- **神通**：境界赋予的标志性能力，以本文第七节为准。
- **招式**：神通在具体场景中的具名用法，以 `05-功法与招式呈现.md` 为准。
- **法印**：礼修发动招式时采用的九拜手势与身法。三者不可混作同一名称。
- 正典名称：明礼境神通为**格物明礼**、招式为**格物辨形**；锡命境统一为**分器授命**；通灵境神通为**阴阳秘听**、招式可称**阴阳窃听**。
- **血食**指供养网络，**血祭**指祭法行为，**血牲**指境界或祭品规格；**尸**是受祭之位，**人牲**是活人祭品，二者不可互换。
- **鼎数**指问鼎子阶，**鼎器**指礼器法宝，**定鼎**指第九境。
- 礼修力量优先称"法度、秩序之力"，巫修力量优先称"血食、生机、祀力"；避免用通用"灵气"代替本世界的力量逻辑。

## 一、设计理念

两条修炼路径分别对应商、周两种文明逻辑，命名风格统一为"两字+境"，便于阅读记忆，同时每个名字都能在商周祭祀语境中找到出处。

- **礼修**：晋升 = "获得秩序认可"。九个境界连起来对应《大学》"格物致知诚意**正心**修身齐家**治国****平天下**"的儒家修身治世脉络——从个人修养一路走到平定天下。讲究**身份匹配、层层册封、不可僭越**，力量增长稳健、可大规模传承。
- **巫修**：晋升 = "献祭/通灵规格提升"。九个境界是一条献祭规模不断升级、人性不断透支的堕落曲线——从感应鬼神，到最后弑神称帝。讲究**直接掠取、代价对等、无需认可**，力量增长迅猛但依赖持续的外部供给（信众、祭品、领地），一旦供给中断便会雪崩式衰退。

两派并非天生对立的种族，而是同源分裂：礼修祖师曾是巫修出身。

## 三、境界释义

### 巫修一线：通灵 → 聚魂 → 为尸 → 血牲 → 祀王 → 冥尊 → 牲祭 → 墟神 → 僭帝

- **通灵**：初能感应鬼神言语，对应"巫"最基础的职能。
- **聚魂**：开始收拢、驱使游魂野鬼为己用。
- **为尸**：借用祭祀中"尸"（活人代祖先受祭、被"借体"）的概念，修士可短暂化身容器，被祖灵/邪神附体施法。
- **血牲**：主动歃血献祭，与鬼神立下"血契"，力量与代价同步暴涨。
- **祀王**：一方之主，靠垄断祭祀权统治领地，"通神者即为王"。
- **冥尊**：吞噬低阶鬼神/亡魂积累的强者，开始半人半灵化。
- **牲祭**（四子阶）：以祭品规格论战力，正式踏入"人性彻底让位于力量"的阶段。
- **墟神**：所过之处生灵尽祭、化为废墟，自身近乎邪神。
- **僭帝**：僭越天位，妄图取代"上帝"本身——呼应世界观中"上帝不容凡人直接觊觎"的禁忌设定，是巫修体系逻辑的终极（也是必然失败的）尽头。

### 巫修四祭分支（祭法流派，非境界）

| 祭法 | 介质 | 功能 | 体系定位 |
|---|---|---|---|
| **燎祭** | 火烟升天 | 通天、侦察、传讯 | 官巫正途 |
| **瘗祭** | 埋地 | 镇压、诅咒、地脉 | 与礼修定序对位 |
| **沉祭** | 沉河 | 盟誓、遗忘、封印 | 条约与秘辛 |
| **血祭** | 生命 | 爆发、契灵、速成 | 现行最强也最易反噬的末路 |

上古四祭并重；太乙朝的制度性堕落是"四祭废其三、独尊血祭"。祭祀中的"尸"原本是尊贵的受祭位，太乙后期才将其降格为可消耗的血食容器。

### 礼修一线：明礼 → 守律 → 正心 → 定序 → 锡命 → 匡道 → 问鼎 → 承天 → 定鼎

- **明礼**：初通礼法根本，明白"礼"是什么。
- **守律**：能自我约束、依律而行，法力开始稳定。
- **正心**：借《大学》"正心"之意，心性与法力同步淬炼，是礼修的关键筑基点。
- **定序**：能以自身为轴，安定一方秩序（结界、镇邪、护民），礼修由守转攻的起点。
- **锡命**：借金文常见的"王锡命"（天子册封赐命）一词，代表正式获得名分、可开宗立府，需靠功绩和联盟"挣"来，不能强修。
- **匡道**：匡正天下道统之偏差，能纠察、镇压巫修邪祟，开始承担"平乱"的责任。
- **问鼎**（四子阶）：借"楚王问鼎"典故——开始有资格觊觎天下共主之位。
- **承天**：正式承接天命，号令一方。
- **定鼎**：借"定鼎中原"典故——真正建立新秩序、终结旧道统，与"问鼎"首尾呼应（先问鼎、后定鼎，一个野心萌发、一个功业完成）。

## 四、第七阶四子阶设计（双方对称，逻辑相反）

**礼修·问鼎境**（子阶靠"名分等级"晋升，对应列鼎制度）

| 子阶 | 对应身份 |
|---|---|
| 一鼎 | 士 |
| 五鼎 | 大夫 |
| 七鼎 | 诸侯 |
| 九鼎 | 天子 |

**文学改造说明**："一鼎"表示获得问鼎资格，并不等同真实礼制中的"士三鼎"；五、七、九鼎才进入公开身份规格。本书采用一、五、七、九四档，是对列鼎制度的修炼化压缩。

**巫修·牲祭境**（子阶靠"祭品规格"晋升，代价逐级加码）

| 子阶 | 祭品规格 |
|---|---|
| 少牢 | 羊豕二牲 |
| 太牢 | 牛羊豕三牲 |
| 人牲 | 活人祭 |
| 国祭 | 举国之民为祭 |

**对比意义**：礼修的晋升靠"被更大范围的人认可"（一步步挣得士、大夫、诸侯、天子的名分），巫修的晋升靠"献出更大规模的生命"（从牲畜到活人到举国）。到"国祭"这一步，巫修理论战力可能反而超过"九鼎"，但也正因如此，巫修在这一阶段最依赖持续的"血食"供给，也最容易被联军掐断补给线而崩盘——这正是"主角核心碾压阶段"的胜负手：不是靠单挑打赢，而是靠瓦解对方的献祭体系。

## 五、突破机制

### 名分三层

礼修一切突破与战力都须落到可追查的"名"上：

| 层级 | 来源 | 可支撑境界与效力 | 限制 |
|---|---|---|---|
| **私名** | 师承、宗族、个人誓约 | 明礼～正心 | 只约束自身，不产生政治权柄 |
| **邦名** | 国君、宗庙、治下承祀与功绩共同认可 | 定序～匡道；问鼎一鼎、五鼎在本邦及盟境内有效 | 离邦衰减；废邦、民变或祀籍被驳会动摇 |
| **天下名** | 太史寮原始祀籍与诸侯会盟共同认证 | 问鼎七鼎以上、承天、定鼎 | 必须公开完成程序；伪造会留下可追查的"名实裂隙" |

太史寮若要废除一国邦名，至少需要**原始祀籍、岁贡承祀记录、盟誓见证**三项互证。祝弗可以拖延、篡改或制造程序瑕疵，却不能以一道口令抹去邦名，否则整个朝贡秩序都会失信。

- **礼修突破 = "锡命"仪式**：功绩只是前提，真正突破发生在授器、宣册、见证、承责的公开仪式中，即"别人把权力与责任交给你，力量才落定"。低阶越级修炼会触发**"僭越之咎"**——不是天雷劈，而是秩序本身排斥你（法度外泄、人心生疑、已修部分崩坏）。
- **巫修突破 = "祭献"即可**：不需要任何人认可，只要祭品到位就能突破，代价是心智侵蚀和"血食依赖症"——供给一断，境界可能不进反退，甚至直接跌落。

## 六、标准寿元

凡人基准寿元约 **80年**。

下表数字只是各派对外使用的估算。礼修寿元的本质是"名在册、秩序仍被承祀则身可存"，巫修寿元的本质是血食网中的连接强度；断供、除名、礼崩都可能使表面年数瞬间失效。

| 阶段 | 巫修寿元 | 礼修寿元 | 说明 |
|---|---|---|---|
| 1 通灵境 / 明礼境 | 80年 | 100年 | 巫修此阶尚未真正"借力"，寿元与凡人无异 |
| 2 聚魂境 / 守律境 | 120年 | 150年 | 巫修靠摄取游魂"打补丁"续命，不算真本事 |
| 3 为尸境 / 正心境 | 180年（虚） | 200年 | 巫修寿元开始"虚高"——借体施法时如常人，卸下时本命反而加速衰老 |
| 4 血牲境 / 定序境 | 300年（系于契灵） | 300年 | 巫修此阶寿元系于血契对象，契灵若灭，寿元瞬间打回原形 |
| 5 祀王境 / 锡命境 | 500年（需血食供养） | 500年 | 巫修寿元需持续人祭"续费"，中断则以年计衰减 |
| 6 冥尊境 / 匡道境 | 900年 | 800年 | 巫修首次反超，但伴随心智兽化加剧 |
| 7 牲祭境 / 问鼎境（各四子阶） | 少牢1500 / 太牢2200 / 人牲3000 / 国祭4000（均为虚数） | 一鼎1200 / 五鼎1800 / 七鼎2500 / 九鼎3500 | 巫修数字更唬人，但"国祭"级寿元完全依赖举国血食，礼修九鼎的3500年则真实、不可剥夺 |
| 8 墟神境 / 承天境 | 6000年（近乎"存在"而非"活着"） | 5000年 | 巫修此阶已近乎非人实体，礼修则正式承接天命 |
| 9 僭帝境 / 定鼎境 | 号称"与神同寿"，实则命悬血食一线 | 与所定秩序同寿——只要道统不灭，寿元不绝 | **核心机制**：巫修的"不死"是假象，一旦被断血食可瞬间归零；礼修的"长生"绑定在自己建立的秩序存续上 |

## 七、各境界专属神通

每个大境界一个标志性神通（第七阶四个子阶共用同一神通，威能随子阶递增）。同阶的礼修/巫修神通尽量形成"索取 vs 给予""个人 vs 秩序"的镜像对比。

| 阶段 | 巫修神通 | 礼修神通 |
|---|---|---|
| 1 | **阴阳秘听**：可听闻鬼神低语，初级占卜 | **格物明礼**：可辨物之"正邪"，识破巫修祭器与禁忌之物 |
| 2 | **摄魂索**：强行摄取周边游魂为己所用 | **克己守心**：布下心防，专克附体/夺舍类攻击 |
| 3 | **借尸还魂**：短暂借体，全力施展祖灵/邪神之力 | **诚意正心印**：以己身心念感化、镇静低阶邪祟与迷失之人 |
| 4 | **歃血契灵**：血祭立契，永久役使一只契灵 | **定序结阵**：结界安邦，庇护一方使其免受邪祟侵扰 |
| 5 | **祀权摄命**：远程抽取治下子民生机为己用 | **分器授命**：可将己身修为分润予属下，团队增益核心技 |
| 6 | **噬魂化力**：直接吞噬灵魂转化为战力，代价是心智损耗 | **匡道正气**：展开正气领域，压制范围内的邪术与巫修神通 |
| 7 | **血祭天罚**：以祭品规格换取毁灭性范围打击，规格越高破坏越烈 | **问鼎轻重**：直指对手权柄之"轻重"，可看穿并削弱其"名不正"的力量 |
| 8 | **化域为墟**：将一方生地化为永久产灵废土 | **承天景命**：召天命加持己方全军，大规模战场级增益 |
| 9 | **僭越九天**：强行争夺"神位"，短暂改写周边法则，但极不稳定 | **定鼎安九州**：永久确立一方秩序法则，近乎"重塑规则"级终极神通 |

### "问鼎轻重"适用规则

第七阶礼修神通及一切"名不正则力弱"的衍生招式，必须遵守：

1. **作用对象**：只对借名分、祀权或血食网导流的力量生效；对肉身蛮力、祝由虫蛊、无主凶物及断供后失控的饕餮纹无效。
2. **发动要件**：必须指出一项可验证的"名实不符"，例如伪锡命、盗祭、强征之祀或越器铸鼎，不能空喊对方"不义"。
3. **证据权重**：原始祀籍高于治下承祀实况，承祀实况高于合法礼器规格。史官和文书因此可直接影响战局。
4. **巫修反制**：移祭、假祀、篡籍、胁迫承祀可以短时伪造连接，逼礼修先调查再质问。
5. **误判代价**：判断错误会损伤发动者自己的锡命，严重时临时失鼎。问鼎是权柄对赌，不是嘴炮。

具体招式见 `05-功法与招式呈现.md` 第六节，所有招式均受以上规则约束。

## 八、可用于剧情的设计细节

- **第4阶"歃血契灵" vs "定序结阵"** 是很好的转折点标志：巫修从这里开始"投资"外部力量（契灵），礼修从这里开始"投资"外部秩序（结界护民）——都是"借助外物"，但方向完全相反，对应"礼修开始反压"节点。
- **第7阶"血祭天罚" vs "问鼎轻重"** 建议作为中后期高光对决场景：巫修一方靠"国祭"级献祭打出毁天灭地的一击，礼修主角却能用"问鼎轻重"直接质疑并瓦解对方力量的"合法性"，让强大的攻击因"名不正言不顺"而后继乏力/反噬自身——把"寿元虚高会崩"的机制在正面对决里具象化。
- **寿元机制的伏笔**：可在中期通过某个巫修角色"寿元突然暴跌"的惨状，提前给读者埋下"血食断绝即崩"的视觉冲击，为终章的体系性崩溃做铺垫。
- **尸解仙与"为尸境"的呼应**：真实道教"尸解"概念（假死脱壳飞升）可设定为——礼修体系里极少数人能反过来利用巫修的"为尸"逻辑，但用于"金蝉脱壳"式的重生/渡劫，而非被夺舍，可作为后期彩蛋或高阶功法。
- **礼崩乐坏的机制化**：若某地"礼"的秩序被破坏（僭越者太多、礼法崩坏），可设定该地域的礼修全体修炼效率下降甚至倒退，把"礼崩乐坏"这个历史概念变成会影响战力数值的"环境状态"，适合做剧情转折的 machinery。

### 会盟阵 / 多人合祭之礼

会盟阵是礼修弥补个体战力短板的集体仪轨，不是临时堆人数：

1. 至少三方各自拥有有效邦名；
2. 事先订立载明权责与退出条款的盟书；
3. 钟负责同步、尊负责汇聚，一件符合持阵者合法鼎数的主器负责定序；
4. 合击效力最多临时提升一个大境，且不能借阵跨过天下名门槛；
5. 必须完成"具—祝—献"，战时简礼只能降级发动。

各方必须保留退出权；强迫合祭会异化为巫修式血食掠夺。阵法被打断时会反噬所有参与者的邦名，甚至引发盟友撤认。

### 血食供养的断裂

第三境起的巫修若要继续破境，必须拥有固定祭所、承祀人口或可追溯贡赋构成的祀域。毁祭坛、截人牲与血玉、切断祀籍所对应的承祀关系，会使连接按日衰减；越依赖国祭，跌落越快。供养网的地理与物资见 `02-势力与地图.md`。
