# 整体大纲与宏观导航

> **文档职责**：本文只回答五卷各自解决什么问题、跨卷长线如何递进与收束。
>
> **正典分工**：章节顺序与具体桥段以 `09-分卷分章细纲.md` 为准；人物以 `06`、`07` 为准；机制以 `01` 为准；势力与供养网以 `02` 为准；卷一前两章的文风与场景以 `10-开篇试写.md` 为准。
>
> 全书约 160 章。各卷章数、标题和施工细节不在本文重复维护。

## 一、全书命题与胜负逻辑

### 一句话故事

一个曾被礼法交出母亲的边地少年，重新理解"礼"不是服从，而是界定何事不可为；他从挣得一邦认可开始，联合诸侯、夺回历史解释权，最终以可退出、可追责、可传承的秩序瓦解依赖强迫献祭的血食王朝。

### 全书核心问题

> 当一套秩序曾经伤害过人，人应当抛弃秩序，还是重建一套不再以牺牲无辜为代价的秩序？

姬怀瑾和子珏面对的是同一道题：前者选择在旧礼失败处重新立界，后者在改革失败后向速效力量投降。两人不是单纯的正邪对照，而是"重建体系"与"被体系异化"的两种结果。

### 终局胜因

全书胜负只由两条主因共同完成：

1. **外部断供**：联盟截断玄鸟道、夺取沉牲渊、毁坏祭坛、策反血食产地，使太乙朝无法继续维持国祭。
2. **内部改祀**：史牧提供真名与原始祀籍，祝由隔绝血契回流，苏鸢改写国祭名序，使剩余血食导向空祀。

饕餮纹失控是断供后的后果；姬彝只补足残缺镇纹；玄鸟城因守军失供而哗变开门。三者都不得成为独立翻盘按钮。

## 二、跨卷递进轴

### 名分、境界与责任

| 卷 | 主角境界 | 名分阶段 | 获得的不是单纯战力，而是 |
|---|---|---|---|
| 卷一·明礼 | 明礼～正心，卷末定序 | 私名 → 邦名初立 | 对自身选择负责；获得岐国边民与宗庙认可 |
| 卷二·会盟 | 定序～锡命 | 邦名稳固并进入盟境 | 代表岐国缔约；承担盟友退出与阵法反噬 |
| 卷三·问鼎 | 匡道～一鼎、五鼎、七鼎 | 邦名 → 天下名 | 接受太史寮、诸侯会盟与天下记录的公开审视 |
| 卷四·血食 | 七鼎～承天～定鼎 | 天下名完成 | 对断供、战争与新秩序的全部后果负责 |
| 卷五·礼崩 | 定鼎之后，不再升级 | 检验天下名 | 证明新程序能否约束胜利者本人 |

**定鼎发生在卷四末，是全书力量与战争高潮。卷五是定鼎后的制度考验，不是第二次升级。**

### 供养网阶段

| 卷 | 供养链功能 | 主要载体与地点 |
|---|---|---|
| 卷一 | **见贡**：让主角看见岁贡、人牲与祀籍如何压迫个体 | 玄鸟道、流巫还籍录、母亲双名 |
| 卷二 | **争贡道**：资源与交通成为联盟的现实成本 | 荆铜山、玄鸟道支线、祝由尸瘴 |
| 卷三 | **争祀籍**：供养关系从物资战升级为历史解释权之争 | 太史寮原始记录、伪锡命、会盟 |
| 卷四 | **断供**：外部资源战与内部改祀同步兑现 | 沉牲渊、血玉、祭坛、国祭名序 |
| 卷五 | **防篡改**：新秩序也可能垄断祀籍和锡命 | 边地复核、伪锡命、程序公开 |

### 主角内外弧

| 阶段 | 外在成长 | 内在问题 |
|---|---|---|
| 卷一前段 | 无力保护母亲，礼修停滞 | "礼若护不住人，为何要守？" |
| 卷一后段 | 由正心走向定序 | 理解礼首先是对不义之命说"不可" |
| 卷二 | 学会结盟与授权 | 发现自愿联合比个人正确更困难 |
| 卷三 | 争天下名、成为盟主 | 接受名分意味着自己也必须被质疑 |
| 卷四 | 承天、定鼎 | 不以胜利之名复制强迫供养 |
| 卷五 | 接受新一代质疑 | 承认自己建立的礼也会僵化 |

主角与父亲的关系不必以彻底和解收束。姬承代表"在弱小时以妥协保存制度"，姬怀瑾代表"制度若不能拒绝不义便失去意义"；两人可以彼此理解代价，却不互相宣布对方完全正确。

## 四、核心配角的跨卷职责

| 人物 | 主要卷次 | 必须完成的功能 |
|---|---|---|
| **姬承** | 卷一为主，后续回响 | 执行礼送、承担父亲与大宗伯的双重责任；与主角形成"保存礼 / 重建礼"之争 |
| **姬祝** | 卷一、四 | 保存礼送程序副本；教授祝辞边界；以"祝"职参与终局镇纹 |
| **姜续** | 卷二～五 | 提出会盟战略；奄国暗线短期有效但有代价；降卒之争迫使主角承认原则的成本；终局与主角互相修正 |
| **姒清** | 卷二～五 | 由治水与盟约建立关系；作为邦名担保人作独立政治决定；卷五在主角未到场时处理边地危机 |
| **史牧** | 卷三～五 | 保存原始祀籍、使太史寮实际易主；为问鼎与改祀提供证据；卷五接受对新太史寮的监督 |
| **苏鸢** | 卷三～四 | 从错误情报与共谋责任走向改祀；代表从体系内部使其空转，代价不是默认死亡 |
| **姬彝** | 卷三末～五 | 交出残缺镇纹并纠正最后一段历史；终局只补一笔；卷五承认自己的制度也非永恒答案 |
| **子珏** | 卷三～五 | 以改革失败解释其选择，不免除罪责；卷四失去权柄，卷五以凡人身份成为旧秩序的活证词 |

三种反抗必须保持差异：

- 辛荼 / 蘅：从体系中逃出，只切断一支血契；
- 苏鸢：留在体系内部，通过改祀使其空转；
- 姬彝：在体系之外建立可传承的新制度。

## 五、五卷宏观导航

### 卷一·明礼

**核心问题**：礼若不能保护一个无辜的人，还有没有存在的意义？

- **开卷状态**：十一岁的姬怀瑾只明礼形，不明礼为何物；辛荼旧名被太乙暗探重新叫起。
- **结构铰链**：岐国国君定策、姬承执礼，母亲被礼送并身亡。四年跳切后，主角仍困在怨恨与守律之间。
- **认知转折**：甲骨残片证明母亲只切断过一支血契。主角明白"拒绝不义之命"是礼的起点，但尚不能由此推导天下断供战略。
- **卷末高潮**：他在边患中不靠血脉识人，而从祭器、仪轨和利益关系查出暗桩；边民与宗庙共同认可其功绩，邦名初立、突破定序。
- **人物代价**：父子裂痕不能在本卷轻易和解；礼送不是抽象制度错误，而是国君定策、姬承执行、姬祝留证的共同结果。
- **下卷接口**：吕国使者到来，奄国血玉贡使进入视野，个人家难转向诸侯政治。

### 卷二·会盟

**核心问题**：不靠强迫的联盟，能否在危机中真正形成力量？

- **开卷状态**：主角只有邦名，离开岐国后效力衰减；他必须用承诺而非境界说服吕国与姒国。
- **中段转折**：荆铜山与玄鸟道支线出现尸瘴，祝由以"救路换禁地"入场；姒清通过治水与资源分配成为盟约参与者，而非联姻奖品。
- **原则代价**：主角坚持在盟书中保留退出条款，延误出兵并造成一处前哨失守；这使"礼数较真"第一次付出人命代价，也使后续合祭不至于异化为强迫血食。
- **卷内高潮**：会盟阵发动前有盟友要求退出。主角拒绝强迫合祭，阵势一度残缺；盟友在保有退出权后自愿归阵，胜利才成立。
- **名分落点**：战后两国以战功、盟书与阵中责任为证公开锡命；卷三开篇，主角再因承担匡正诸侯祀序的责任突破匡道，境界不从定序直接跳到问鼎。
- **人物推进**：姜续指出主角公开表态的政治风险；姒清以礼器与继承权为邦名担保；婚礼是盟约结果，不是感情线终点。
- **卷末转折**：姜续被迫离吕并投奔岐国；太乙朝将岐国列为重点目标；奄国的血玉供养关系成为下一阶段隐患。
- **下卷接口**：联盟可以打赢一场战争，却仍没有天下承认，问题转向"谁有权记录胜利"。

### 卷三·问鼎

**核心问题**：战场上的胜利，若没有可信的记录与程序，能否成为天下名分？

- **开卷状态**：主角先由锡命突破匡道，随后取得问鼎资格；一鼎、五鼎仍只由邦名支撑，权柄不能稳定越出盟境。
- **主线推进**：史牧保存原始祀籍，祝弗以程序和人事控制太史寮。姜续支持内部倒戈，不表示他已放弃权谋，而是选择更适合名分战的手段。
- **主高潮**：抢救史牧和原始记录只是动作高潮；真正高潮是会盟当众揭伪、废黜祝弗、使史牧暂摄太史寮。主角接受公开认证与责任后稳固七鼎天下名。
- **并行线**：苏鸢以宫廷女祝身份递出国祭名序情报，也暴露自己曾因错误选择伤及故国遗民；子珏旧政必须通过恢复三祭的旧令和子瞻清洗案呈现。
- **军事副线**：联盟击溃崇国主力，但残部、降卒与祀权退入玄鸟城。崇国败退不能取代太史寮主高潮。
- **卷末转折**：全面战争不可逆；姬彝交出残缺镇纹，众人首次试镇失败，证明祖师知识并非完整答案。
- **下卷接口**：联盟取得天下名，却必须证明自己能承担断供战争造成的死亡、叛变与秩序真空。

### 卷四·血食

**核心问题**：如何在不复制血食逻辑的前提下，瓦解一套靠强迫供养维持的天下体系？

- **开卷状态**：先处理崇国残部与降卒。主角宽释保住多数人，却因小部复叛造成姒国伤亡；姜续的严惩论被部分验证。
- **前半推进**：联盟沿玄鸟道分兵断供，子珏启动国祭；苏鸢筹划改祀。主角此时仍是七鼎，不能在卷初提前承天。
- **承天锚点**：太乙鼎现世时，主角在公开誓约中承担联军、断供与战后安置的责任，才获得承天资格。
- **中点逆转**：奄国大巫裹挟国君与血玉军背刺。姜续暗线曾救人，也促使奄国提前清洗摇摆派；这是两人的第三次正面交锋，最终双方承认各有正确与代价。
- **全书高潮**：外部断供与内部改祀同步生效。子珏力量空转，奄军契约动摇，饕餮纹因失供而失控。
- **镇纹原则**：姬彝补一笔后力竭；姬怀瑾、姒清、史牧、姬祝与祝由参与者共同完成会盟镇纹。
- **卷末结局**：玄鸟城守军哗变开门；子珏以凡人存活；重建后的太史寮与诸侯会盟为太乙鼎正名，主角在公开锡命中定鼎。
- **下卷接口**：旧王朝已经失败，但新秩序是否只是换了一批人掌握祀籍，尚未得到回答。

### 卷五·礼崩

**核心问题**：胜利者建立的程序，能否约束胜利者自己？

- **开卷状态**：定鼎已经完成，本卷不再安排境界突破或第二次大战。
- **现实冲突**：重新锡命引发资源分配争议；奄国残部与太乙遗老伪造锡命、篡改边地祀籍，制造局部礼崩。
- **解决方式**：姒清和史牧在主角未到场时先恢复记录与公开复核，军事行动只负责收束，证明新秩序不能依赖共主亲临。
- **理念回响**：姜续与主角继续争论宽严，但不重复前三次结论；年轻礼修质疑"格物正心"是否窄化姬彝最初的德、命、彝之学。
- **人物收束**：姬彝承认制度会老去；子珏以凡人身份面对旧制受害者；姬怀瑾接受新一代有权质疑自己的定鼎。
- **终章余韵**：太乙鼎已被重新定名，但鼎名不是永恒真理。结尾留下"秩序必须不断接受名实检验"的开放答案。

## 六、卷一开篇执行原则

第一、二章正文已经定稿为示范，见 `10-开篇试写.md`：

1. 第一章以暗探临岐、流巫还籍录和父母失态建立危机；礼修法度通过动作显形，不用旁白讲体系。
2. 第二章连续推进偏殿核验；主角窃听，辛荼旧名出现，血脉只产生疤痕灼热，獬只对公开言行的名实矛盾示警。
3. 第三章起严格按 `09` 卷一章表执行，不在本文维护另一套章序。

卷一写作还须遵守：

- 母亲线在前十章内持续推进，不插入与危机无关的长篇日常；
- 第十一章明确"四年后"，残片在第十四章出现，正心顿悟在第二十章，不能与母亲之死同期完成；
- 岐山旧事、岁贡、人牲和贡道背景必须嵌入查籍、出行与人物选择，不写独立设定讲解章；
- 同辈轻视只作短场景，不扩写成常规废柴打脸线；
- 主角第一次实战辨形必须从器物和仪轨破绽进入调查，不能一眼识破人物。

## 七、节奏与重复控制

| 卷 | 主高潮 | 不得抢占主高潮的副线 |
|---|---|---|
| 卷一 | 母亲真相后的正心重释 + 边患挣得邦名 | 同辈考核、单纯升级 |
| 卷二 | 保留退出权的会盟阵胜利 | 联姻仪式、吕国营救 |
| 卷三 | 太史寮文书战与七鼎天下名 | 崇国覆灭、苏鸢情报 |
| 卷四 | 外部断供 + 内部改祀 | 奄国背刺、饕餮镇纹、破城不得取代双主因 |
| 卷五 | 伪锡命危机与程序自证 | 普通军事平叛、再次定鼎 |

每卷卷末不都用"突破 + 敌人来信"收束。境界变化必须是责任落地的结果；没有名分变化的卷末，应以关系破裂、供养链变化或程序失效作为钩子。
