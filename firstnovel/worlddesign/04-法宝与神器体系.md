# 法宝与神器体系

## 一、设计理念

延续"礼器 vs 祭器/巫器"的对立逻辑：

- **礼修法宝**：脱胎于青铜礼器（食器、酒器、水器、乐器、兵礼器），核心逻辑是"规格对应身份，身份决定能调用的力量上限"，法宝本身不作恶，关键在于持有者是否"名正言顺"。
- **巫修法宝**：脱胎于占卜、祭祀、通灵用具（甲骨、巫傩面具、蛊虫、血玉祭坛），核心逻辑是"法宝即容器，容器里封存/寄宿的鬼神或亡魂越强，法宝越强"，法宝本身往往带有意志或饥饿感，越用越依赖持续"投喂"。
- **术语**：礼器承载的是法度与秩序之力，巫器吞吐的是血食、生机与祀力。本文避免用"本命法宝、法杖、灵气"等通用修仙词替代本世界机制；完整术语规范见 `01-修炼体系.md` 第〇节。

## 二、礼修法宝：礼器体系

### 食器类——炼化、镇压、号令

| 礼器 | 法宝定位 |
|---|---|
| **鼎** | 最核心的礼修法宝载体：集体炼制的礼器范、镇压邪祟的镇物、号令一方的权柄象征三重合一。铸鼎需要经过完整的"锡命"仪轨，私自铸鼎（尤其铸造超过自身身份规格的鼎）会直接触发"僭越之咎"。 |
| **簋** | 与鼎配套使用的"养器"，用于团体渡气、赈济/庇护治下修士与百姓，是"分器授命"神通的常见载体。 |
| **甗** | 复合型礼器范，可同时蒸炼药材、铜液与祭余，多用于宗门集体炼制，而非个人法宝。 |
| **豆** | 小型盛物礼器，常被制成传讯/传物的"信器"，用于诸侯国之间传递盟书、信物。 |

### 酒器类——封存、传递、通感

| 礼器 | 法宝定位 |
|---|---|
| **爵** | 最基础的初养爵器，用于温养个人法度、练习具礼与献礼，是入门者最常随身携带的礼器。 |
| **觚** | 细高酒器，炼成后可用于"导祝"，是礼修远程招式常见的祝辞媒介。 |
| **尊** | 大型盛酒礼器，可临时储存大量秩序之力供集体调用，是会盟阵必备的共力枢纽。 |
| **卣、觥** | 带盖有提梁的酒器，可用于封存记忆、誓言或"活的证词"（比如封存某段关键对话/契约的完整场景，作为呈堂证供或历史存证），带有轻微的"史官"记录属性。 |
| **彝** | 礼器总称，引申为"常法"，炼成的彝器往往被设定为**规则/律法的具象化载体**，可用于临时"定规矩"（小范围内强制约束言行，类似真言结界）。 |

### 水器类——净化、映照、占验

| 礼器 | 法宝定位 |
|---|---|
| **盘** | 大型水器，炼成后可作"照心镜"，映照对象是否心怀邪祟、是否受巫修蛊惑，是礼修阵营侦测巫修渗透的重要手段。 |
| **匜** | 舀水器，多用于净化仪式，可洗去轻度诅咒/污秽之气，是随身携带的"祛邪小物"。 |

### 乐器类——共鸣、指挥、结界

| 礼器 | 法宝定位 |
|---|---|
| **钟** | 大型军阵/宗门共用法器，敲响后可同步激活多人身上的礼修印记，是会盟阵必备的同步信号法器。 |
| **镈** | 与钟配套的小型打击乐器，多用于个人施法时"定节奏"，辅助复杂仪轨不出错。 |
| **磬** | 石制乐器，声音可直接干扰巫修的"通灵"类神通，是专门克制巫修的战场压制型法器。 |

### 兵礼器——授权、征伐

| 礼器 | 法宝定位 |
|---|---|
| **戈** | 基础兵礼器，唯有获得"锡命"的诸侯/将领才能合法持有并激发全部威力，是"合法暴力"的具象化。 |
| **钺** | 规格高于戈，历史上专属"专征伐"之权的象征（真实历史中"钺"是天子授予方伯征伐权的信物），可设定为只有问鼎境以上、且经共主或联盟正式授权者才能激发，私自持有钺而妄动兵戈会被视为"僭越"的铁证。 |

## 三、巫修法宝：祭器/巫器体系

| 法器 | 定位 |
|---|---|
| **甲骨** | 占卜法器，可破译"天机残页"般的卜辞碎片，预知短期未来或探查因果线索，是巫修阵营的情报/预言核心手段。 |
| **巫傩面具** | 通灵/驱邪/伪装身份的多用途法器，戴上后可短暂借用面具所刻画的鬼神身份行事，也常被用于潜伏、易容。 |
| **血玉** | 用于封存血契/献祭对象魂魄的载体，是"歃血契灵"神通的常见媒介，主要产自奄国及绥服矿地；这一资源使奄国被太乙朝的供养网牢牢绑定。 |
| **蛊虫/尸蛊** | 南荒祝由一脉与巫修均有涉猎的活体法器，可用于诅咒、夺舍、远程操控，是最贴近"以毒攻毒"逻辑的巫修手段。 |
| **祭坛法阵** | 不便携带的大型法器，多固定于领地内，是"祀权摄命""血祭天罚"等神通的施法基座，摧毁祭坛是瓦解巫修一方战力的直接手段。 |

### 四祭法器对应

| 祭法 | 典型法器 / 祭所 |
|---|---|
| 燎祭 | 烟鼎、火坛，负责传讯与通天 |
| 瘗祭 | 埋牲玉、地钉，负责镇压与地脉咒缚 |
| 沉祭 | 石牲、沉符，负责盟誓、遗忘与封印 |
| 血祭 | 血玉、血坛，负责契灵与爆发；太乙朝现行主流 |

## 四、饕餮纹：贯穿两派的特殊符文

饕餮纹（青铜器最经典的兽面纹）设定为一种**镇物与噬力兼具的双面符文**，正邪两用，是全书可以反复利用的一个关键意象：

- **巫修用法**：饕餮纹作为"噬纹"，刻于法器或自身皮肉之上，可无差别吞噬地脉生气与周遭生命力转化为己用，威力大但极易失控反噬持有者。断供后失控的噬纹已无明确祀权，不受"问鼎轻重"直接削弱。
- **礼修用法**：礼修祖师曾研究出"以纹镇纹"之法，将饕餮纹反向封印在鼎器上作镇物，专门用来吸收、囚禁失控的巫修凶物或逃逸的邪灵，是礼修阵营处理"巫修烂摊子"的常规手段。
- **剧情钩子**：可设定大陆上存在若干上古饕餮纹遗物，礼巫双方都想争夺，谁先掌握"镇纹"的完整心法，谁就能在后期决战中更从容地应对对方失控的力量。

## 五、法宝的获得方式（对应两派晋升逻辑）

- **礼修法宝**：必须经过完整的"礼器铸造仪轨"——需选定合规材料、举行祭告仪式、由达到对应境界的宗门长老或共主/诸侯"开光锡命"，法宝才能真正为己所用。私自炼制超出身份规格的礼器会遭遇"僭越之咎"同款反噬。这个流程天然把"造法宝"变成一件需要政治资源、人脉、功绩背书的大事，而非闭门造车。
- **巫修法宝**：只需要合适的祭品/宿主即可速成，甚至可以直接掠夺他人已炼成的法宝、强行"改造"为己用（代价是法宝会残留原主人的怨气，可能伺机反噬）。

### 会盟阵的器备边界

会盟阵必须同时具备钟、尊与一件符合持阵者合法鼎数的主器；主鼎规格不得超过持阵者邦名或天下名允许的上限。阵中各方必须有独立邦名、盟书与退出权。强迫合祭会把礼器异化为抽取他人的血食容器；阵法被打断则反噬所有参与者的邦名。完整规则见 `01-修炼体系.md`。

## 六、贯穿全书的核心神器构想

| 神器 | 设定 |
|---|---|
| **太乙鼎** | 太乙朝共主的至高神器，也是巫系"上帝"解释权的物化象征。谁掌它谁具备名义上的天下共主身份。终局主角阵营不靠掠夺，而由已重建的太史寮与诸侯会盟通过锡命程序重新为其正名。 |
| **甲骨天机残页** | 上古流传的一批残缺卜辞，记载着关于"礼巫同源"祖师往事、以及"血食体系"死穴的关键信息，可作为主角探寻门派真相的重要线索物。 |
| **镇纹古鼎** | 礼修祖师当年封印自身巫修过往、也封印了一头上古饕餮凶物的初代法器，可作为主角门派的镇派之宝，也是"以纹镇纹"技法的活教材。 |

## 七、法宝等级与位阶体系的对应关系

法宝品级大致对应使用者所需的最低境界门槛，具体细分与命名可在后续功法细化阶段一并完成，此处仅列大致对应关系，供写作时参考：

| 使用门槛 | 礼修法宝规格 | 巫修法宝规格 |
|---|---|---|
| 明礼～正心 | 爵、觚级法器 | 甲骨、巫傩面具级法器 |
| 定序～匡道 | 尊、彝、簋级法器 | 血玉、蛊虫级法器 |
| 问鼎（含四子阶） | 鼎级法器（子阶越高，可镇之鼎越大越尊贵） | 祭坛级法阵（规格随牲祭子阶提升） |
| 承天以上 | 钟、钺等国之重器级 | 近乎"半神格"的活体祭器 |
