# 分卷分章细纲

> 本文档在 `08-整体大纲与开篇.md` 的分卷规划基础上，进一步展开更细粒度的分章细纲。目前先完成**卷一·明礼**的完整分章（约 30 章），后续各卷可按相同颗粒度逐步补充。

## 卷一·明礼（约 30 章）分章细纲

| 章 | 标题 | 内容概要 |
|---|---|---|
| 1 | 暗探临岐 | 引子。太乙朝暗探悄然抵达岐国，以查验户籍为名展开调查，气氛压抑却不完全点明缘由，制造悬念。 |
| 2 | 明礼境的少年 | 引出主角日常：修为长年停滞在明礼境，家族地位不高不低，与父亲姬承的疏离感初次显现。 |
| 3 | 岐山旧事 | 通过长辈闲谈或家族典籍，侧面带出岐国立国渊源与礼修祖师的传说，此时"姬彝"尚只是传说中的名字，读者与主角都不知其仍然在世。 |
| 4 | 岁贡随行·上 | 主角随岁贡队伍前往边境贡道驿站，第一次亲眼目睹被征作"人牲"的队伍。 |
| 5 | 岁贡随行·下 | 目睹太乙朝收贡官员对小国使者的傲慢与欺压，主角心中对"礼法秩序"的怨恨种子悄然埋下。 |
| 6 | 暗探叩门 | 查验事件正式发酵，暗探的调查触及主角家族的敏感地带，家中气氛骤然紧张。 |
| 7 | 朝堂之议 | 姬承与岐国国君及众臣商议对策，妥协的氛围逐渐形成，主角在旁听闻只言片语。 |
| 8 | 决断 | 姬承在保全岐国大局与保护妻子之间做出痛苦抉择，选择交出主角母亲，父子爆发第一次正面冲突。 |
| 9 | 诀别 | 母亲被带走前与年少主角的诀别场景，留下"礼不可失，命亦不可负"的遗言。 |
| 10 | 归途无声 | 母亲在被"礼送"回朝途中自尽的消息传回岐国，主角陷入长期的怨恨与自我封闭。 |
| 11 | 数年 | 时间跳跃至主角青年时期，具体展开修为长期停滞在明礼～守律境的困境与心结。 |
| 12 | 同辈的轻视 | 一场家族/宗门内部的修炼考核，主角因修为落后而受挫，也借此展现其"认死理、不擅辩解"的反差性格。 |
| 13 | 獬的陪伴 | 引入灵宠"獬"的日常互动片段，缓解前文的沉重基调，埋下"獬能辨是非"的伏笔。 |
| 14 | 遗物 | 主角在整理母亲遗物时，意外发现一片来历不明的甲骨残片。 |
| 15 | 残片之谜 | 尝试破译残片时因涉及巫修知识而屡屡受阻，主角第一次隐约意识到自己身世中"半巫"的部分。 |
| 16 | 血脉初显 | 情绪剧烈波动下，左手旧疤第一次明显发烫，隐藏血脉初次显露端倪，主角开始怀疑自己身世的全貌。 |
| 17 | 父亲的沉默 | 主角就母亲的真相质问姬承，姬承选择部分坦白，父子关系出现裂痕，却也有一丝艰难的松动。 |
| 18 | 残片破译 | 借助姬承提供的线索或家族典籍，主角逐步破译残片的关键内容。 |
| 19 | 真相 | 完整还原母亲当年"自绝血食"的真相，主角认识到母亲并非软弱的牺牲品，而是主动的反抗者。 |
| 20 | 顿悟 | 正心境突破的高光场面，结合 `05-功法与招式呈现.md` 中的施法仪轨与法印细节具象化呈现。 |
| 21 | 边患初起 | 岐国边境传来异动消息，具体的内政/边患危机正式拉开序幕。 |
| 22 | 请命 | 主角主动向父亲与国君请命参与处理边患，遭遇质疑——"你连守律境都未坐稳，凭什么"。 |
| 23 | 出行 | 主角首次以"办事者"身份离开家族核心圈，携灵宠"獬"启程前往边境。 |
| 24 | 边境异象 | 抵达边境后发现危机背后并不单纯，隐约察觉巫修渗透/暗桩活动的蛛丝马迹。 |
| 25 | 格物辨形初显威 | 主角运用"格物辨形"神通识破一名伪装的巫修暗桩，是新境界能力的实战首秀。 |
| 26 | 姒国边民 | 边患牵涉与姒国接壤的边界纠纷，主角初步接触姒国相关人物，为卷二联姻线埋下伏笔。 |
| 27 | 化解危局·上 | 主角尝试以礼修智慧而非单纯武力手段，展开对边患冲突的调停与化解。 |
| 28 | 化解危局·下 | 危机成功化解，主角第一次真正"挣得"当地民众与官员的认可，而非依靠出身或血脉。 |
| 29 | 认可与忧虑 | 姬承对主角处理方式既感认可又心存忧虑——锋芒渐露恐引来更大关注；一封来历不明的信件或使者悄然出现。 |
| 30 | 风起 | 卷末。主角修为正式突破定序境；吕国使者抵达岐国（或崇国方面已有所动作）作为开放性钩子，引出卷二"走向大局"。 |

## 后续规划

- 卷二～卷五的分章细纲将按同等颗粒度陆续补充，建议在卷一细纲通过审阅、明确写作节奏偏好后再展开，以便及时应用调整意见。
- 分章细纲中标注的具体人物、地点名称如有调整（例如姒国边民角色、边患的具体性质），需要同步回写到对应的设定文档中，保持全文档体系的一致性。
