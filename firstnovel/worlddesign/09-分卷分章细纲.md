# 分卷分章细纲

> 本文档在 `08-整体大纲与开篇.md` 的分卷规划基础上，进一步展开更细粒度的分章细纲，现已完成全书五卷的完整分章（合计约 160 章）。

## 卷一·明礼（约 30 章）分章细纲

| 章 | 标题 | 内容概要 |
|---|---|---|
| 1 | 暗探临岐 | 十一岁的姬怀瑾与已养两年的獬在祖庙外目睹太乙暗探抵达；"流巫还籍录"直接触发危机。 |
| 2 | 明礼境的少年 | 暗探入偏殿核验旧籍，怀瑾违令窃听，借父亲与来使的礼法交锋展现家世与能力边界；辛荼旧名首次出现，危机继续推进。 |
| 3 | 旧籍里的岐山 | 姬祝调取蘅的告祖祝辞与岐国旧籍，来使发现岁贡承祀记录缺页，宣布推迟内籍复核、先查玄鸟道支线；他借姬彝出走旧事质疑岐国收留流巫的合法性。 |
| 4 | 沉牲渊 | 姬承被迫带队前往贡道驿站取证；怀瑾作为宗族名册中的关联人随行，第一次看清人牲队伍。 |
| 5 | 血册 | 驿站旧册显示辛荼最后一次祀力回响与岐国贡队重合；收贡吏借人牲和小国使者立威，怀瑾开始把母亲危机与整条贡道联系起来。 |
| 6 | 内籍复核 | 暗探按约复核府中内籍，辛荼与蘅的双名疑点正式进入程序，调查从试探升级为公开质询。 |
| 7 | 朝堂之议 | 姬承与岐国国君及众臣商议对策，妥协的氛围逐渐形成，主角在旁听闻只言片语。 |
| 8 | 决断 | 岐国国君定下交人之策，姬承以大宗伯身份执行宾礼名义下的"礼送"，父子第一次正面冲突。 |
| 9 | 诀别 | 母亲辛荼、礼名蘅被带走前与主角诀别，留下"礼不可失，命亦不可负"的遗言；姬祝暗存程序违法副本。 |
| 10 | 归途无声 | 母亲在礼送途中切断自身真名与押送祭坛的一支血契，随后身亡；传回岐国的公文只写"畏罪自尽"，主角因此长期怨恨礼法。 |
| 11 | 四年后 | 章首明确"四年后"，跳至主角青年时期，展开修为长期停滞在明礼～守律境的困境与心结。 |
| 12 | 只明其形 | 宗门考核要求复演礼送仪轨，怀瑾动作无误却无法认同其义，法度当场溃散；同辈轻视只作压力，不安排打脸。 |
| 13 | 獬指旧匣 | 獬对母亲遗物匣上"无主旧物"的签条示警，怀瑾据此发现匣底夹层；日常互动直接引向残片，不单设陪伴章。 |
| 14 | 遗物 | 主角在整理母亲遗物时，意外发现一片来历不明的甲骨残片。 |
| 15 | 残片之谜 | 姬祝帮助辨认残片祝辞，并要求怀瑾只问器物与仪轨、不以祝辞窥测人心；巫修知识受阻使他第一次意识到自身"半巫"痕迹。 |
| 16 | 血脉初显 | 情绪剧烈波动下，左手手背旧疤发烫，只提示附近有为尸/借体异常，不能识人、读心或定罪。 |
| 17 | 父亲的沉默 | 主角就母亲的真相质问姬承，姬承选择部分坦白，父子关系出现裂痕，却也有一丝艰难的松动。 |
| 18 | 残片破译 | 借助姬承提供的线索或家族典籍，主角逐步破译残片的关键内容。 |
| 19 | 真相 | 还原母亲切断押送祭坛与自身真名之间一支血契的真相；主角只确认血食连接可断，尚未得到天下战略。 |
| 20 | 正心有证 | 顿悟只解除心结；怀瑾在宗庙公开否认不义礼送、承诺追查贡道真相，姬祝主持祝辞、姬承提交真实记录作见证，完成私名层级的授器、宣册与承责后才突破正心。 |
| 21 | 边患初起 | 岐国边境传来异动消息，具体的内政/边患危机正式拉开序幕。 |
| 22 | 请命 | 主角主动请命处理边患，遭遇质疑："正心初成、尚无邦名与治事之功，凭什么代表岐国？" |
| 23 | 出行 | 主角首次以"办事者"身份离开家族核心圈，携灵宠"獬"启程前往边境。 |
| 24 | 边境异象 | 抵达边境后发现危机背后并不单纯，隐约察觉巫修渗透/暗桩活动的蛛丝马迹。 |
| 25 | 格物辨形初显威 | 主角以格物辨形发现暗桩所持祭器与公开身份的仪轨不合，再结合调查锁定其人；能力不能直接辨忠奸。 |
| 26 | 姒国边民 | 边患牵涉与姒国接壤的边界纠纷，主角初步接触姒国相关人物，为卷二联姻线埋下伏笔。 |
| 27 | 两国一水 | 主角不以武力驱赶姒国边民，而公开水源、祭地与暗桩证据，迫使双方共同处理冲突。 |
| 28 | 邦名初得 | 危机化解，主角第一次真正挣得当地民众与官员认可，而非依靠出身或血脉。 |
| 29 | 认可与忧虑 | 姬承对主角处理方式既感认可又心存忧虑——锋芒渐露恐引来更大关注；一封来历不明的信件或使者悄然出现。 |
| 30 | 风起 | 主角因边民与宗庙共同认可而获得邦名、突破定序；吕国使者到来，奄国血玉贡使的消息同时沿玄鸟道传来。 |

## 卷二·会盟（约 35 章）分章细纲

|---|---|---|

| 9 | 献牲之议 | 吕国朝堂就是否继续向太乙朝进献人牲爆发激烈争论，各派先公开自身所依赖的贡项。 |
| 10 | 谁食其利 | 主角公开表态；獬对一名口称反对人牲、名下却分享血玉贡利的臣子示警，主角仍须以账册核实，明确灵兽不能代替证据。 |
| 11 | 理念初摩擦 | 姜续认为主角表态"操之过急、授人以柄"，两人第一次意见不合。 |
| 12 | 密约 | 姜续私下透露部分吕国内幕，释放合作善意，但仍留一手。 |
| 13 | 归途 | 主角结束首次出使返程，途经姒国边界正式停留。 |
| 14 | 姒国相见 | 姒清与主角因荆铜山水脉、陶范商队和贡道纠纷共同协作。 |
| 15 | 边患再起 | 玄鸟道支路出现尸瘴与虫蛊，岐姒边境同时受阻。 |
| 16 | 联手 | 两人发现崇国借清剿之名争夺贡道，礼巫常规手段都无法彻底解除尸瘴。 |
| 17 | 崇国斥候 | 崇国前锋以尸蛊污染贡道；怀瑾疤痕察觉附近借体异常，却误把源头归到祝由尸傀，险些伤及合作者，最终从器物痕迹找出潜伏的为尸斥候，并以"救路换禁地"建立第一次交换。 |
| 18 | 请援 | 姒国、岐国意识到威胁，紧急商议结盟事宜。 |
| 19 | 结盟之议 | 姒国主和派提出接受太乙朝加急伪锡命换取安全，联姻与正式结盟因此陷入僵局。 |
| 20 | 未告之押 | 姒清未先征得主角同意，押上本国礼器与继承权为联盟邦名担保；两人在承担政治后果后才确认彼此心意。 |
| 21 | 崇国挑衅 | 崇国以"清剿蛮荒余孽"为名大举压境，实则试探岐姒联盟。 |
| 22 | 会盟阵筹备 | 三方有效邦名订立盟书，备齐钟、尊与合法主器；主角坚持补全退出条款导致出兵延后，一处前哨因此失守。 |
| 23 | 决战前夜 | 主角面对延误造成的伤亡仍拒绝删去退出权；姬承与姒国老臣的支持与忧虑并存。 |
| 24 | 盟书缺角 | 一方盟友因担心邦名受损临阵要求退出，主角拒绝强迫合祭，阵势一度残缺。 |
| 25 | 自愿归阵 | 盟友在保有退出权的前提下自愿归阵，会盟阵正式发动；胜因是共同承担而非强行抽取。 |
| 26 | 钟鸣之后 | 联军以弱胜强击退崇国先锋，但部分参与者因阵法受创承受邦名反噬。 |
| 27 | 战后锡命 | 两国以战功、盟书与阵中责任为证，为主角举行公开锡命；他获得跨入盟境行使权柄的资格，联姻仪式提上日程。 |
| 28 | 联姻 | 婚礼同时是两国邦名盟约；姒清以本国礼器作担保，不只是政治婚姻。 |
| 29 | 吕国震动 | 岐姒会战大胜的消息传至吕国，进一步激化吕国内部路线之争。 |
| 30 | 姜续遇险 | 吕国保守派/巫修既得利益者对姜续发难，构陷或直接加害。 |
| 31 | 密信 | 姜续冒险传信岐国求援，暴露自己已到生死关头。 |
| 32 | 驰援 | 主角紧急决断是否出手救援姜续，涉及是否干涉他国内政的两难。 |
| 33 | 营救 | 成功营救姜续，一场紧张的行动戏，姜续正式脱离吕国。 |
| 34 | 投奔 | 姜续正式投奔岐国，成为主角阵营首席谋主，两人首次坦诚交心。 |
| 35 | 风声 | 太乙朝把岐国列为重点处置对象；奄国血玉贡使暧昧示好，姜续提醒其供养链远比吕国更深。 |

| 18 | 姒清的建言 | 姒清提出稳健方案，展现"定序"一脉务实风格，与主角默契加深。 |
