# 正文写作进度

> 本文件跟踪 `firstnovel/正文/` 下各卷正文的写作与复核进度。
> 创作规约见 `../novelrules.md`；分章蓝图见 `../worlddesign/09-分卷分章细纲.md`。

## 工作流程（每章）

1. 读 `novelrules.md` + `09` 当章及相邻章 + 按章型的最小正典读取集。
2. 主模型（Claude Opus 4.8）起草，单章约 5000 字。
3. **换模型复核**：由 `gpt-5.6-sol-high` 按 `novelrules.md` 第十二节"章后自检"逐项审校，给出可落地修改清单。
4. 据复核意见定稿；必要时先回写 `09`/对应设定再定稿。
5. 提交（每章一次逻辑提交），更新本进度表。

## 目录规则

- 路径：`正文/卷X·卷名/第NN章-标题.md`（NN 为两位章序）。
- 每文件首行为 `## 第N章·标题`，正文紧随其后。
- 第 1、2 章沿用 `worlddesign/10-开篇试写.md` 的正典范本，仅搬运、未改写。
